TLS для панели 3x-ui

Если панель использует собственный CA/самоподписанный сертификат, получите его
из доверенного источника (например, с самого сервера по SSH), сохраните рядом
с проектом в certs/panel-ca.pem и добавьте:

В config.toml, в соответствующий [[panels]]:

    ca_file_env = "XUI_MAIN_CA_FILE"

В .env:

    XUI_MAIN_CA_FILE=/app/certs/panel-ca.pem

В volumes сервиса bot в compose.yml:

    - ./certs:/app/certs:ro

Имя/IP в base_url должно быть включено в SAN сертификата. Если сертификат
выписан на домен, используйте этот домен в base_url. Проверка TLS остаётся
включённой. Каталог certs не копируется в Docker-образ и в архив исходников.

TLS для API проверяющего узла

controller_url может содержать IP (например, https://203.0.113.1:8443), если
сертификат сервера содержит этот IP в SAN. Когда API контроллера тоже использует
собственный CA, добавьте controller_ca_env = "CONTROLLER_CA_FILE" в [settings],
CONTROLLER_CA_FILE=/app/certs/controller-ca.pem в .env.probe и смонтируйте каталог
certs в сервис probe аналогично примеру выше. Это отдельная настройка от CA панели.
Nginx перед контроллером использует сертификат и ключ сервера; самому боту и
агенту для доверия требуется только публичный сертификат/CA.
