Основные изменения для пользователя:

- Под выбранной подпиской отображаются её срок, оставшееся время и дата окончания по московскому времени.
- Для бессрочных подписок выводится «Бессрочная подписка». Срок обновляется из личного кабинета, последнее значение сохраняется на устройстве.
- В окне проверки обновлений показывается список основных изменений новой версии.
- Сохранены подписки, выбор сервера, маршрутизация и настройки DNS.
- APK проверяется по SHA-256 перед установкой.

Установите APK поверх текущего приложения. Для получения сроков выполните вход в личный кабинет.
