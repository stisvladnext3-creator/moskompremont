# Android 0.1.37: сроки подписок

Исходный код: 06d90c1817a065aad5cb08b441c4b3ed524dfc97.
Сборка, модульные тесты, lint и сценарий эмулятора: https://github.com/stisvladnext3-creator/moskompremont/actions/runs/45999516449

Проверены бессрочная и помесячная подписки, выбор правильного срока для выбранной подписки, дата окончания по Москве, обратный отсчёт, отсутствие ложной бессрочности при неизвестном сроке, обновление после продления и сохранение данных при повторном открытии.

Подпись APK проверена официальным apksigner из Android Build Tools 37.0.0. Используется прежний сертификат издателя:
8309db39687334c10a96d86240bb18d8723832e74d64b33b1033a498a5e39b96

Публикация выполняется workflow Publish signed Android release только после проверки SHA256 и подписи, чистой установки и обновления поверх подписанной предыдущей версии на эмуляторах Android 7/API 24 и Android 15/API 35. Отчёты доступны в артефакте signed-android-installation соответствующего workflow.

Проверки эмуляторов не заменяют испытание на всех физических устройствах. Срок поступает из существующего API кабинета; изменение сервера и миграция базы для этой функции не требуются. Ссылка, добавленная вручную без известного срока, показывает «Срок не указан».
