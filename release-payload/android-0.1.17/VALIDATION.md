# Проверка Android 0.1.17

Код APK: `1c86c0da9f198e409449b657df53a66e70db39f3`. [Успешная сборка и проверки CI](https://github.com/stisvladnext3-creator/moskompremont/actions/runs/43591124908), 14 ноября 2026 года. Документ обновлён после сборки; код APK не изменён.

Прошли JVM-тесты MoskomPolicyTest и остальные :app:testFdroidDebugUnitTest, компиляция, сборка debug/release и Android test APK, :app:lintFdroidDebug, проверка на эмуляторе Android 15/API 35 x86_64.

На настоящем интерфейсе Compose и нативном VPN-процессе проверены:

- Вход через локальный API, выбор подписки и изоляция её серверов, DNS, правила Russia, восстановление выбора после пересоздания Activity.
- Проверка подключения настоящим Xray/VLESS, системное разрешение VPN, повторные включения/выключения и отзыв подписки.
- «☰ → Управление подписками»: пустой список, защита подписок кабинета, отмена удаления, Enter и D-pad, удаление неактивной подписки без отключения VPN, остановка при удалении активной, удаление всех её профилей.
- Подтверждение сохраняется при пересоздании Activity; удалённая подписка не возвращается после повторного открытия. Отдельные ключи сохраняются. Пустая подписка без индекса серверов тоже удаляется. Несуществующий ID отвергается.
- Встроенная справка, доступные имена значков, клавиатура и D-pad, читаемые системные значки в тёмной оболочке.

Стенд использует вымышленные учётные данные и локальный HTTP/VLESS-сервер. Рабочие аккаунты и подписки не изменялись. При упаковке проверены ru.moskompremont.vpn, версия 0.1.17, versionCode 5001700, minSdk 24, выключенный debuggable, CRC ZIP, точное совпадение логотипа сайта, Russia, все четыре ABI и ELF/16 КБ для 64 бит.

Публичный APK подписан тем же постоянным ключом, что 0.1.13; сертификат SHA-256 8309db39687334c10a96d86240bb18d8723832e74d64b33b1033a498a5e39b96. Подпись и SHA-256 проверены после подписания. Ключ и пароль не входят в публичные файлы.

Сайт v20 отдельно проверен с PHP 8.4 и MariaDB 11.4: продление после подтверждения оплаты, сохранение ссылки, календарные месяцы, истёкший/неуказанный срок, запрет продления чужой/удалённой/бессрочной подписки, дублирующее и одновременное подтверждение, отказ в оплате и откат при искусственной ошибке. Браузер прошёл путь клиент → оплата → подтверждение администратором → новый срок на ширинах 390/1280 px. Страница скачивания сохраняет актуальные резервные ссылки при ошибке API и запоздавшем старом ответе.

**Not run**

- Физические телефоны ARM64/ARMv7 и старые Android: устройство не подключено. Состав ABI/ELF проверен, запуск выполнен на x86_64.
- Озвучивание TalkBack: нет канала проверки речи. Семантика и управление клавишами проверены отдельно.
- Полный цикл обновления опубликованного APK на телефоне: устройство не подключено. Сертификат совпадает с предыдущим выпуском, versionCode выше.
- Принудительный аппаратный сбой записи MMKV: аппаратный сбой не моделировался. Обработчик хранит снимок под существующей блокировкой и восстанавливает его при ошибке записи.
- Вход реального клиента из подписанного APK и работа с его VPN: реальные учётные данные не предоставлялись.
- Загрузка более нового Russia и откат повреждённого комплекта: проверялся актуальный закреплённый комплект; обновление без смены DNS/режима и нативный запуск прошли.
