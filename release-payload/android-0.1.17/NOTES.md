В меню ☰ Windows 0.3.17 и Android 0.1.17 добавлено «Управление подписками». В разделе можно удалить вручную добавленную подписку со всеми её серверами. Есть подтверждение; удаление активной подписки выключает VPN, удаление другой сохраняет подключение. Подписки из кабинета управляются через сайт.

Сайт v20: выбор новой подписки или продления своей подписки. После ручного подтверждения оплаты срок добавляется автоматически, ссылка сохраняется. Повторная обработка не начисляет месяцы дважды. Страница скачивания обновлена до Windows 0.3.17 / Android 0.1.17.

Для сайта загрузите файлы архива v20 и импортируйте private/migrations/010-order-renewals.sql в действующую базу. Приложения устанавливайте поверх предыдущих версий. APK подписан прежним постоянным ключом.

Проверки: JVM, сборка, lint, эмулятор Android API 35 с настоящим Xray/VLESS и жизненным циклом VPN; Windows GUI/установщик; PHP/MariaDB и браузерный путь оплаты/продления. Подробности и границы проверки — VALIDATION.md. Исходники APK и SHA256SUMS включены.
