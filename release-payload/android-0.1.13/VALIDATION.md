# Проверка Android 0.1.13

Код приложения: `ee1578af37d10f590aeebb0c19011e418fa322b0`.

[Успешная сборка и проверки CI](https://github.com/stisvladnext3-creator/moskompremont/actions/runs/43572770278), 14 ноября 2026 года. Документ добавлен после сборки; код APK не изменён.

Прошли:

- `:app:testFdroidDebugUnitTest`, включая шесть тестов `MoskomPolicyTest`: выбор группы по ID, пустые группы, сроки и ответы API, DNS, версии, контрольные суммы и исключение предварительных выпусков.
- `:app:compileFdroidDebugKotlin`, `:app:assembleFdroidDebug`, `:app:assembleFdroidDebugAndroidTest`, `:app:assembleFdroidRelease`.
- `:app:lintFdroidDebug`.
- `:app:connectedFdroidDebugAndroidTest` на Android 15/API 35, x86_64: пустой кабинет; вход с открытой клавиатурой; две раздельные подписки; выбор сервера; DNS; проверка актуальности Russia с сохранением режима и DNS; пересоздание экрана с теми же ID; реальная проверка выбранного VLESS-соединения; системное разрешение VPN; повторные запуск и остановка через IPC; отзыв активной подписки; обновление ссылки; сохранение рабочей группы при ошибке загрузки и сообщение о частичном обновлении; ручной ключ после выхода; внутренняя справка; Enter, пробел и D-pad; доступные имена значков; читаемые системные значки при светлой теме Android.

Стенд использует вымышленные учётные данные и локальный HTTP/VLESS-узел. Положительный результат проверки соединения проходит через настоящий нативный Xray/VLESS-клиент. Для обхода ошибки системного Pixel Launcher в headless-образе отключён только этот launcher тестового эмулятора.

При упаковке отдельно проверяются идентификатор `ru.moskompremont.vpn`, версия, минимальный SDK 24, выключенный `debuggable`, целостность ZIP, точное совпадение пикселей логотипа, геоданные Russia, библиотеки всех четырёх ABI, их ELF-архитектура и выравнивание сегментов 16 КБ для 64 бит. Публикуемый APK подписывается постоянным отдельным ключом; подпись и SHA-256 проверяются после подписания. Ключ не входит в публичные файлы.

Страница скачивания проверена на ширинах 390 и 1280 px; переполнения нет. Выбор версий Windows/Android проверен отдельно: числовая сортировка, исключение чужих ссылок и рабочая резервная ссылка при недоступности API. Архивы сайта проверены на целостность и отсутствие рабочего `private/config.php`, паролей и клиентских CSV.

**Not run**

- Работа на физических телефонах ARM64/ARMv7 и старых Android: физическое устройство не подключено. Эти ABI проверены по составу и ELF; запуск проверен на эмуляторе x86_64.
- Голосовые объявления TalkBack, их порядок и активация с озвучиванием: в среде нет канала проверки речи. Семантика значков и управление клавиатурой проверены отдельно.
- Установка обновления поверх предыдущего опубликованного Android-релиза: это первый выпуск. Выбор версии и SHA-256 проверены тестами; APK подписан постоянным ключом, открытие системного установщика реализовано, но полный цикл обновления на телефоне не проверен.
- Загрузка более нового комплекта Russia и откат при повреждённой загрузке: во время проверки источник уже соответствовал включённому комплекту. Проверены запрос актуальности, первоначальная установка комплекта, сохранение DNS/режима и запуск нативного ядра с этими правилами.
- Вход реального клиента на основном сайте из подписанного APK: данные реального клиента не предоставлялись. Проверен совместимый с PHP API локальный стенд; рабочие аккаунты не создавались и не изменялись.
