# Android 0.1.34 — исправление подписи APK

Исходный релиз: 97671e8bad9e7d39fb314b4c9e17798ce43d4ace; исправление CI: 7269242.

Причина ошибки установки: опубликованный APK не был подписан. Его SHA-256 70565ba2e4eba2ed2c13c6ae38a9bc6764e1429483260d30de0277a01097d98b совпадал с опубликованной контрольной суммой, CRC ZIP был корректен, но apksigner возвращал DOES NOT VERIFY / Missing META-INF/MANIFEST.MF.

Пакет подписан сохранённым постоянным ключом; SHA-256 сертификата: 8309db39687334c10a96d86240bb18d8723832e74d64b33b1033a498a5e39b96. apksigner verify проходит для API 24–37, один подписант, схемы v2/v3. Код, ресурсы и библиотеки (541 запись вне META-INF) побайтно совпадают с исходным APK. Архив соответствующих исходников не изменён.

Проверены package ru.moskompremont.vpn, versionName 0.1.34, versionCode 5003400, minSdk 24, targetSdk 37, отсутствие debuggable, четыре ABI, ELF-архитектуры и выравнивание 16 КБ для 64-битных библиотек, CRC и логотип.

Публикация блокируется до успешной проверки подписанного APK на эмуляторах Android 7/API24 и Android 15/API35: чистая установка и запуск; затем установка 0.1.29 и обновление до 0.1.34 с сохранением UID, firstInstallTime и маркера в приватных данных приложения. Отчёты install.txt и снимки экрана сохраняются в артефакте signed-android-installation workflow Publish signed Android release для ветки distribution/android-0.1.34-repair.

Исходная сборка приложения проходила JVM-тесты, сборку обеих разновидностей APK, lint и UI/VPN-проверки Android 15 в CI https://github.com/stisvladnext3-creator/moskompremont/actions/runs/44823738200. При исправлении подписи код приложения не менялся.
