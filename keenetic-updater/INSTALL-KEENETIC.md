# Подключение автообновления Keenetic/XKeen

## Владельцу сайта — один раз

1. Сделайте резервную копию файлов сайта. Распакуйте **moskom-keenetic-site-update-0.1.1.zip** в папку сайта, где расположен `account.html`. Содержимое папок `assets`, `api`, `private`, `downloads` нужно объединить с существующими. `private/config.php`, база пользователей, QR, файлы клиентов и страница скачивания приложений в архив не входят. Для исправления уже установленной 0.1.0 достаточно малого архива из `UPDATE-KEENETIC.md`.
2. В той же MySQL-базе, которую использует `private/config.php`, импортируйте `private/migrations/011-router-devices.sql`, **если ещё не подключали пакет OpenWrt**. Если таблица `internet_router_devices` уже есть, повторный импорт не требуется. Миграция использует существующую `internet_users`; базовые таблицы действующего кабинета должны быть установлены.
3. Сохраните действующую защиту каталога `private`. `private/xray-outbound.php` — вспомогательный PHP-код; он не должен открываться клиентам как отдельная страница.
4. Проверьте, что открывается `https://moskompremont.ru/downloads/keenetic/install.sh` и скачивается файл `https://moskompremont.ru/downloads/keenetic/0.1.1/mkr-xkeen-updater_0.1.1-1_all.ipk`. Прямой вход на `api/router-agent.php` без кода должен вернуть JSON с HTTP 401. При размещении кабинета в подпапке архив загружается в неё; кабинет сам сформирует команду с правильным адресом.
5. Откройте админку → **Keenetic**, выберите клиента и включите ему вкладку. В «Ключи для роутеров» назначьте этому клиенту одиночный ключ **vless://**. Загружать JSON-файл конфигурации для этого способа не нужно.
6. Обновите страницу кабинета (Ctrl+F5). Клиент увидит в Keenetic форму подключения. В разделе админки **Роутеры** видны устройства, последняя связь и результаты применения; там можно заменить назначенный устройству ключ или отключить код.

Обновлять домен/IP можно существующей функцией массовой замены ключей в админке. Для ротации UUID/параметров измените сам ключ или назначьте устройству другую запись через «Заменить ключ». До первой проверки обновления у клиента должны быть рабочие Entware и XKeen с Xray. Сам XKeen этот пакет не устанавливает.

## Клиенту — установка на роутер

1. Войдите на сайт → **Keenetic**. Укажите название роутера, выберите свой ключ, нажмите «Создать код подключения».
2. Откройте SSH **именно Entware** на роутере. Установленный в KeeneticOS компонент SSH обычно занимает порт 22; в таком случае Entware часто слушает **222**. Без него Entware может использовать 22. Адрес и пароль возьмите из вашей настройки Entware. Пример с типичным адресом Keenetic:

   ```sh
   ssh root@192.168.1.1 -p 222
   ```

   Встроенная командная строка Keenetic с приглашением `(config)>` не является Entware shell. Нужен SSH-сеанс с доступом к `/opt/bin/opkg` и команде `xkeen`.
3. Скопируйте из кабинета **команду установки**, вставьте в SSH и выполните. Команда получает установщик с сайта сервиса, а не с GitHub. Он проверит пакет и установит инструменты из вашего Entware feed.
4. Когда появится «Код устройства», вставьте код из кабинета и нажмите Enter. Ввод кода скрыт. Код выбирает только указанный ключ; пароль от сайта не передаётся.
5. После сообщения о подключении проверьте:

   ```sh
   mkr-xkeen status
   ```

   Состояние `current` означает, что файл уже содержит актуальный ключ; `applied` — что ключ заменён и процесс Xray запущен. Следующая проверка произойдёт через пять минут. Результат появится также в кабинете. При новом ключе в режиме уведомлений придёт уведомление на сайте.

## Если файл или блок не удалось выбрать автоматически

В XKeen ключ обычно находится в `/opt/etc/xray/configs/04_outbounds.json`. Файл с другим названием, включая `04_inbound.json`, тоже поддерживается, если внутри есть `.outbounds` и блок `protocol: "vless"` с `tag`.

При нескольких VLESS-блоках и отсутствии единственного совпадения UUID укажите нужный файл и его существующий `tag`:

```sh
mkr-xkeen target /opt/etc/xray/configs/04_outbounds.json proxy
mkr-xkeen check
```

Замените `proxy` на реальный `tag` вашего блока, если он другой. Пакет не выбирает случайный сервер.

## Управление и восстановление

```sh
mkr-xkeen mode notify  # Только уведомлять о новом ключе
mkr-xkeen mode auto    # Автоматически заменять
mkr-xkeen check        # Проверить сейчас
mkr-xkeen retry        # Повторить применение после исправления ошибки
mkr-xkeen rollback     # Вернуть последний бэкап и включить уведомления
mkr-xkeen unlink       # Отключить обновления, сохранив подключение XKeen
```

Если установленный Xray не понимает транспорт/параметр нового ключа, рабочий файл сохраняется и появляется `manual`. Обновите Xray штатными средствами XKeen либо исправьте ключ, затем выполните `retry`. При неудачном перезапуске пакет возвращает предыдущий файл и включает режим `notify`.

После сброса пароля кабинета, истечения годового кода или его отзыва создайте новый код и выполните `mkr-xkeen setup`, затем вставьте новый код. Для сайта в подпапке передайте точный адрес API: `mkr-xkeen setup https://example.ru/internet/api/router-agent.php`.

Поддерживаются роутеры с работающими Entware/XKeen/Xray. Номер KeeneticOS сам по себе не гарантирует совместимость; модели без Entware и установки с Mihomo требуют другого решения. Исходные настройки можно восстановить вручную из `/opt/var/lib/mkr-xkeen/previous.conf`; эта копия содержит секретный ключ.
