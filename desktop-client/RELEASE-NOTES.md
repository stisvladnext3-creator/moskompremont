- Бургер-меню: обновление правил Russia, проверка обновлений приложения, DNS, справка и выход.
- Обновлены геоданные Russia. Кнопка правил получает свежие версии, проверяет контрольные суммы и сохраняет прошлый комплект при ошибке загрузки. Выбранная политика и DNS сохраняются.
- Проверка новой версии при запуске, каждые 6 часов и вручную. Окно «Доступно обновление …» предлагает «Обновить сейчас» или «Позже»; отсрочка — на сутки. Установщик проверяется по SHA-256, подключение завершается перед установкой, приложение открывается после обновления.
- DNS: автоматически из Russia, Cloudflare 1.1.1.1, Google 8.8.8.8, Quad9 9.9.9.9 и свой IP/DoH. Готовые варианты используют DNS-over-HTTPS для запросов через VPN; прямой и начальный DNS берутся из Russia.
- Оформление в цветах сайта и оригинальный логотип «МКР»: иконка EXE, окна, панели задач, трея и ярлыка рабочего стола. Ярлык создаётся автоматически, без дополнительных галочек.

- Установщик с одной кнопкой, локально для текущего пользователя, без отдельной установки .NET.
- Russia, DNS, геоданные и SRS заранее включены в комплект.
- Исправлена иконка включения: используется векторная графика, независимо от шрифтов Windows.
- «Проверить доступность» проверяет выбранный сервер через VPN-ядро с компьютера клиента, результат показывается в миллисекундах.

- Пароль не сохраняется. Сессия хранится с защитой DPAPI текущего пользователя Windows; длительность входа определяется сайтом.
- Подключение через системный прокси Windows после проверки соединения; TUN для всего устройства отсутствует.
- Восстановление прежнего прокси при выходе и аварийном завершении.
- Подписки и настройки отделены от обычного v2rayN; действующих подписок в дистрибутиве нет.

Обновиться можно через «☰ → Проверить обновления приложения» или вручную: завершите приложение через «Выход» и запустите новый установщик поверх старой версии. Подписки и данные кабинета сохраняются. Менять базу или загружать обновление PHP не требуется.

Windows-сборка без коммерческой цифровой подписи, возможен SmartScreen. Проверка SHA-256 не заменяет цифровую подпись издателя.
