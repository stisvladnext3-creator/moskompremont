Обновление МосКомпРемонт VPN для Windows 10/11 x64, на основе v2rayN 7.25.6.

- Установщик с одной кнопкой, локально для текущего пользователя, без отдельной установки .NET.
- Russia, DNS, геоданные и SRS заранее включены в комплект.
- Исправлена иконка включения: используется векторная графика, независимо от шрифтов Windows.
- «Проверить доступность» проверяет выбранный сервер через VPN-ядро с компьютера клиента, результат показывается в миллисекундах.
- «Статус сервиса» получает цвет, объявление и доступность серверов из работающего API moskompremont.ru.
- «Войти в кабинет» принимает почту и пароль сайта. Все активные подписки клиента загружаются автоматически, изменения ссылок проверяются раз в минуту.
- Отозванные и истёкшие подписки убираются после успешной синхронизации. Добавленные вручную через «+» ссылки сохраняются отдельно.
- Пароль не сохраняется. Сессия хранится с защитой DPAPI текущего пользователя Windows; длительность входа определяется сайтом.
- Подключение через системный прокси Windows после проверки соединения; TUN для всего устройства отсутствует.
- Восстановление прежнего прокси при выходе и аварийном завершении.
- Подписки и настройки отделены от обычного v2rayN; действующих подписок в дистрибутиве нет.

Перед обновлением завершите приложение через «Выход» и установите новую версию поверх старой. API текущего сайта уже поддерживает эти функции; менять базу или загружать обновление PHP не требуется.

Windows-сборка без коммерческой цифровой подписи, возможен SmartScreen. CI проверяет вход через локальный тестовый API, несколько подписок, замену ссылки, истечение и отзыв, DPAPI, проверку недоступного тестового сервера, обновление с 0.1.3 и удаление. Реальный вход с вашим аккаунтом и подключение с действующей подпиской нужно проверить на клиентском ПК.

В этом же выпуске есть соответствующие исходники GPL-3.0 и контрольные суммы. Инструкция входит в установленное приложение.
