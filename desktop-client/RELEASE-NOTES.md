Исправлены лишние разрывы соединения при работе с несколькими подписками:

- Повторный выбор уже активной подписки, сервера или маршрутизации сохраняет соединение.
- Фоновая синхронизация кабинета, обновление другой подписки и повторная загрузка пустой/недоступной подписки не перезапускают VPN.
- Повторная загрузка выбранной подписки с теми же параметрами сервера тоже сохраняет соединение, даже если при импорте изменились внутренние ID записей.
- Переподключение выполняется после загрузки, только если изменились параметры выбранного подключения. Отозванная или истёкшая активная подписка отключается сразу.
- Выход из кабинета сохраняет подключение по ключу, добавленному вручную.

Выбор подписки перед выбором сервера сохранён. Пустая подписка не подставляет серверы других групп.
