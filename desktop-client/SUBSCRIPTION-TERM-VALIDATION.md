# Отображение срока выбранной подписки

Изменение от 27 ноября 2026. Windows 0.3.58, macOS 0.2.35, Android 0.1.37.

## Поведение

Под выбором подписки отображается её собственный срок: «Бессрочная подписка», оставшиеся дни/часы/минуты либо «Срок истёк». Ни отсутствие даты, ни отсутствие данных не считаются бессрочностью: в этом случае выводится «Срок не указан». Для помесячной подписки также показана дата окончания по московскому времени.

Данные поступают из существующего API `account.php?action=subscriptions`: `term_kind`, `expires_at`, `remaining_seconds`, `is_expired`. Новая миграция базы не нужна. Синхронизация кабинета выполняется прежним механизмом раз в минуту, визуальный обратный отсчёт — раз в 15 секунд по монотонному времени.

При переключении подписки плашка использует её ID в аккаунте, а не дату предыдущей подписки. Сроки кэшируются по аккаунту и ID, без подписочных URL и секретов. После перезапуска доступна последняя полученная дата; после выхода из аккаунта кэш удаляется. Вручную импортированная ссылка получает срок, если после входа её URL точно и однозначно совпал с собственной подпиской кабинета; без такой связи срок остаётся неизвестным.

Изменение только срока обновляет метаданные, не отмечает содержимое ссылки изменённым и не запрашивает перезапуск VPN. Существующее поведение удаления истёкших/отозванных подписок из доступных подключений сохранено. Эта плашка не продлевает подписку и не управляет сроком доступа на VPN-сервере.

## Границы

Тесты используют изолированные аккаунты и подписки; реальные клиентские данные не запрашивались. macOS legacy проверяется на современном CI с сохранённой целью macOS 11; физические Big Sur/Windows 8/ARM-телефоны не испытывались. Результаты эмуляторов и тестового движка не означают проверку каждого устройства или доступности каждого удалённого VPN-сервера.

Страница скачивания обновляется отдельно файлом `module/download.html`. Загрузка архива этой страницы на PHP-хостинг остаётся действием владельца сайта; публикация в GitHub не изменяет файлы действующего хостинга.
