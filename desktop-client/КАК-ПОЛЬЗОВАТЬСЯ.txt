МОСКОМПРЕМОНТ VPN — Windows x64

Установщик автоматически создаёт ярлык «МосКомпРемонт VPN» на рабочем столе и в меню «Пуск». Иконка — логотип сайта «МКР».

1. Установите приложение кнопкой «Установить».
2. Скопируйте выданную ссылку-подписку из личного кабинета.
3. Нажмите «+» в приложении. Список серверов загрузится автоматически.
4. Выберите нужную подписку, затем сервер из неё и маршрутизацию Russia.
5. Нажмите большую кнопку «Включить VPN». После проверки появится «VPN включён».

СПРАВКА В ПРИЛОЖЕНИИ
Кнопка «Справка» внизу окна или в меню ☰ открывает встроенную страницу с коротким описанием всех кнопок. Для чтения интернет не нужен; список прокручивается. «Понятно» закрывает справку.

ВЫБОР ПОДПИСКИ
Если ссылок несколько, выберите нужное название в поле «Подписка». В поле «Сервер» будут только серверы этой подписки. Число рядом с названием показывает количество серверов. Отдельные ключи, добавленные через «+», доступны в группе «Отдельные ключи». Выбранная подписка и сервер сохраняются. При переключении работающий VPN переподключится. Если в подписке нет серверов, обновите её: подключение из другой подписки автоматически не подставляется.

ЛИЧНЫЙ КАБИНЕТ
Нажмите «Войти в кабинет» и введите почту и пароль от moskompremont.ru. Приложение автоматически получит все активные подписки аккаунта. Изменения ссылки и данных в кабинете проверяются раз в минуту при доступном интернете; «Обновить серверы» запускает обновление немедленно. Пароль на диске не сохраняется. Сессия защищена DPAPI текущего пользователя Windows; «Мой кабинет» → «Выйти из кабинета» удаляет локально сохранённый вход и полученные из кабинета подписки. Ссылки, добавленные через «+», остаются.
После успешной синхронизации истёкшие, удалённые и отвязанные на сайте подписки удаляются из приложения. При ошибке сети уже полученные данные сохраняются. Если сайт завершил сессию, войдите повторно. Подписки не включены в установщик: каждый клиент входит своим аккаунтом.

ДОСТУПНОСТЬ
Выберите сервер и нажмите «Проверить доступность». Проверка проходит с вашего компьютера через временное VPN-ядро, без включения системного прокси. При успехе показывается, например, «258 мс».
«Статус сервиса» показывает объявление, цвет и список доступности с сайта. Эти данные проверяет ваш сервер мониторинга, поэтому результат может отличаться от проверки с компьютера клиента. Старые результаты отображаются как «Нет свежих данных».

ОБНОВЛЕНИЕ ПРИЛОЖЕНИЯ
Завершите старое приложение кнопкой «Выход» и запустите новый установщик. Устанавливайте поверх старой версии. Личные настройки хранятся отдельно от файлов программы.

БУРГЕР-МЕНЮ (три полоски справа вверху)

«Обновить правила Russia» получает свежие списки маршрутов, DNS пресета и геоданные runetfreedom. Выбранный режим «Всё» / «Всё, кроме РФ» / «Заблокированное» сохраняется. Новое ограничение попадёт в приложение после добавления сервиса в исходные списки Russia. При неудачной загрузке используется предыдущий комплект. Во время применения активное VPN-подключение перезапускается. Для пакетов геоданных может потребоваться загрузка около 100 МБ.

«Проверить обновления приложения» проверяет версии сборки МосКомпРемонт. Также проверка выполняется при запуске и каждые 6 часов. При новой версии появится «Доступно обновление …». «Обновить сейчас» скачивает установщик, проверяет SHA-256, завершает VPN-подключение и обновляет программу. После установки она открывается снова. «Позже» откладывает автоматическое предложение на сутки; ручная проверка доступна в любой момент. На компьютерах с проверкой издателя Windows может дополнительно запросить подтверждение запуска: цифровой подписи у сборки нет.

«DNS» меняет DNS внутри VPN-приложения. «Автоматически» — рекомендации Russia. Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9) используют DNS-over-HTTPS для доменов, которые разрешаются через VPN. Для прямых соединений и начального разрешения адресов сохраняются DNS Russia. Можно указать свой IP DNS или HTTPS-адрес DoH. Нажмите «Сохранить DNS»; активное подключение перезапустится. Программы, игнорирующие системный прокси, продолжают использовать собственные настройки DNS.

Кнопка «Обновить серверы» запрашивает обновления добавленных подписок.
Для отключения нажмите большую кнопку ещё раз. «Выход» завершает приложение и восстанавливает прежние настройки прокси Windows. Крестик скрывает приложение в трей; открыть его можно из трея или ярлыком.

Режим этой упрощённой сборки — системный прокси Windows. Он используется браузерами и другими приложениями, которые поддерживают системный прокси. Режима TUN для всего трафика устройства здесь нет.

Russia, его DNS-настройки, маршрутизация и необходимые файлы правил входят в установщик. Интернет во время установки для их скачивания не нужен. Для загрузки подписки и подключения интернет нужен.

Маршрутизация:
«Всё» — штатная политика Russia с общими исключениями.
«Всё, кроме РФ» — политика из пресета Russia для российских ресурсов.
«Заблокированное» — политика из пресета Russia только для выбранных списков.
Точные правила и дата их версии находятся в preset-russia и sources.json. Выбор режима задаёт маршрут, но не гарантирует доступность отдельного внешнего ресурса.

Данные хранятся отдельно от обычного v2rayN:
%LOCALAPPDATA%\MosKomRemontVPN
При удалении приложения личные подписки и настройки сохраняются в этой папке. Для полного удаления своих данных удалите её вручную после выхода из приложения.

За основу взят официальный v2rayN 7.25.6 (2dust), с упрощённым интерфейсом МосКомпРемонт. Подписки не входят в установщик, каждый клиент добавляет свои. Исходники и лицензия GPL-3.0 поставляются отдельным архивом в том же выпуске.

Сборка не имеет коммерческой цифровой подписи. Windows может показать проверку издателя/SmartScreen. Подпись приобретается и добавляется владельцем выпуска; приложение не отключает проверки Windows.

Если не получается подключиться: обновите подписку, попробуйте другой сервер и проверьте, что используется свежая ссылка из кабинета https://moskompremont.ru/account.html.
