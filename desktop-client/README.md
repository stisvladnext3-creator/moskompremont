# МосКомпРемонт VPN для Windows x64

Упрощённый интерфейс на основе официального v2rayN 7.25.6: большая кнопка подключения с векторной иконкой, выбор сервера и Russia, «+» для импорта ссылки, проверка доступности, статус сервиса и вход в личный кабинет moskompremont.ru. Установщик содержит .NET, ядра и заранее загруженный Russia, поэтому не требует скачивать компоненты во время установки.

Это отдельная производная сборка, не официальный выпуск 2dust. Исходный присланный в чат ZIP был больше лимита доступа среды (32 МиБ); за основу взят официальный ZIP с тем же названием, проверенный по SHA-256. Пользовательские подписки в установщик не включены.

## Получение

Сборка создаётся workflow `Build Windows VPN installer` и публикуется в GitHub Releases как предварительный выпуск `moskom-vpn-v0.3.<номер сборки>`. Файлы:

- `MoskomVPN-Setup-<версия>.exe` — установщик Windows 10/11 x64.
- `MoskomVPN-Source-<версия>.zip` — соответствующие изменённые исходники и скрипты.
- `SHA256SUMS.txt` — контрольные суммы.
- `MoskomVPN-Preview.png` — снимок работающего окна на Windows.
- `MoskomVPN-Login.png` — окно входа с тестовыми данными.
- `MoskomVPN-menu.png`, `MoskomVPN-dns.png`, `MoskomVPN-update.png` — меню, DNS и пример окна обновления.

В установщике одна кнопка «Установить», путь фиксирован в текущем профиле Windows. Создаются ярлыки на рабочем столе и в меню «Пуск», затем приложение открывается автоматически. Администраторские права для этого режима не требуются. Сборка без коммерческой цифровой подписи; Windows может показать SmartScreen.

## Подключение

Скопируйте свою ссылку из личного кабинета → нажмите «+» → выберите сервер и маршрутизацию → нажмите большую кнопку. Прокси включается после запуска ядра и проверки исходящего соединения. Кнопка выключения/выход восстанавливает прежние настройки прокси; отдельный процесс восстановления следит за аварийным завершением.

**Режим — системный прокси Windows, для приложений, которые его используют. TUN для всего трафика устройства в этой упрощённой сборке не реализован.** Приложение не заявляет защиту трафика программ, игнорирующих системный прокси.

Россия/Russia включает штатные политики «Всё», «Всё, кроме РФ», «Заблокированное», DNS и геоданные runetfreedom. Версии и SHA-256 закреплены в `build/sources.json`; необходимые SRS-файлы входят в комплект. Данные хранятся в `%LOCALAPPDATA%\MosKomRemontVPN`, отдельно от обычного v2rayN. Они сохраняются при обновлении/удалении приложения. Полная инструкция — `КАК-ПОЛЬЗОВАТЬСЯ.txt`.

## Сайт, вход и доступность

«Войти в кабинет» использует существующие `api/account.php?action=me`, `login`, `subscriptions`, `logout`, с HTTPS, CookieContainer, Origin и CSRF. Пароль не сохраняется; сессия зашифрована DPAPI для текущего пользователя Windows. Сайт может завершить её после смены пароля, удаления аккаунта или истечения срока. На работающем moskompremont.ru проверена доступность API версии 17; обновление PHP и миграция базы для этого приложения не нужны.

Все активные подписки аккаунта сохраняются в отдельных помеченных группах. Каждую минуту запрашиваются актуальные назначения, URL, срок и версия содержимого. Изменившиеся подписки обновляются, отозванные или истёкшие убираются. Только полный авторизованный ответ является основанием для удаления; ошибки сети/JSON сохраняют кэш. Обновление из кабинета и выход не удаляют отдельные ручные ссылки «+». При изменении активной конфигурации приложение отключает и переподключает прокси; при отзыве активной подписки остаётся отключённым.

«Статус сервиса» получает цвет и объявление из `api/service-notice.php`, серверы — из `api/server-status.php`, обновляет раз в минуту и учитывает давность проверок. «Проверить доступность» запускает штатный `SpeedtestService.Realping` для выбранного узла через отдельное тестовое ядро без изменения системного прокси. Это отдельная проверка с компьютера клиента; центральный мониторинг выполняется с сервера.

Перед установкой обновления завершите старое приложение кнопкой «Выход». Установщик обновляет приложение по прежнему пути, данные профиля хранятся отдельно.

## Меню, правила, DNS и обновления приложения

Бургер-меню справа вверху содержит обновление Russia, проверку версии приложения, DNS, справку и выход. Брендинг использует исходный логотип `https://moskompremont.ru/images/logotipmain.png`, сохранённый в `branding/source.json` с SHA-256. ICO содержит размеры 16–256 пикселей. Установщик создаёт ярлыки автоматически с явным IconFilename и AppUserModelID; это же изображение включено в EXE и иконки окна/трея. Фоновый градиент и акценты соответствуют чёрной, бирюзовой и фиолетовой палитре сайта.

Правила обновляются из закреплённых на момент запроса коммитов runetfreedom. Сначала скачиваются и проверяются JSON/DNS, геоданные с SHA-256 из GitHub Releases и необходимые SRS. Комплект переключается после успешной загрузки. Активные данные хранятся отдельно в `%LOCALAPPDATA%\MosKomRemontVPN\routing`, поэтому установка приложения не затирает более свежий комплект. Xray получает каталог через переменную ассетов, sing-box — через путь SRS. При сбое применения сохраняется предыдущий активный комплект. Выбор режима и DNS сохраняется. Кнопка не добавляет домены, которых ещё нет в исходном списке Russia.

Настройки DNS используют штатный `SimpleDNSItem` v2rayN. Автоматический режим восстанавливает DNS активного пресета; три провайдера задают RemoteDNS через DoH, DirectDNS и BootstrapDNS остаются рекомендованными Russia. Поддерживается свой IP/HTTPS DoH. Конфигурации Xray проверяются в CI через `xray run -test`. Сетевые адаптеры Windows приложение не настраивает.

Собственная версия встроена в `MoskomBuildInfo` при сборке. Проверка GitHub Releases выполняется при запуске, каждые 6 часов и вручную. Рассматриваются только теги `moskom-vpn-v` этого репозитория, включая публикуемый канал предварительных сборок, с точными именами установщика и SHA256SUMS. Версии сравниваются численно. Загрузка потоковая, с ограничением размера, HTTPS и проверкой SHA-256; чужие адреса и небезопасные перенаправления отклоняются. При активном VPN загрузки идут через его локальный SOCKS. «Позже» откладывает предложение на сутки. При установке передаётся PID приложения; Inno Setup ждёт его завершения, устанавливает обновление в прежний каталог и запускает приложение. Сборки не подписаны сертификатом издателя, поэтому обычные проверки Windows сохраняются.

CI проверяет меню и диалоги на Windows, шифрование входа, перенос правил и откат после повреждённого DNS, три DoH-пресета/автоматический DNS с настоящим Xray, окно новой версии и отсрочку. Установочный прогон проверяет обновление с 0.2.7, сценарий автоматического запуска после тихого обновления, брендированный ярлык после обновления и после чистой установки. Проверки обновления используют контролируемые метаданные и не запускают загруженный из теста фиктивный EXE.

## Сборка

Нужны Windows x64, .NET SDK 10, Git, Python 3, Inno Setup 6 и доступ к официальным GitHub/NuGet. Команда из PowerShell:

```powershell
./desktop-client/build/Build-Windows.ps1 -Version '0.1.0' -Output './out'
```

Скрипт скачивает закреплённый исходник v2rayN и его подмодули, применяет точные патчи/оверлеи, публикует self-contained Windows-приложение, проверяет официальный ZIP и геоданные по SHA-256, включает Russia и компилирует Inno Setup. Установщик не скачивает компоненты при установке.

Workflow проверяет состояния/откат/отмену, Origin/CSRF, ошибки входа и невалидные ответы, несколько подписок, срок и свежесть мониторинга. GUI на Windows импортирует 30 тестовых серверов и отдельный ключ, проходит реальное окно входа с локальным HTTP API, синхронизацию двух подписок, смену URL, истечение и отзыв, шифрование сессии DPAPI, выход с сохранением ручных ссылок и проверку недоступного тестового узла. Системный прокси остаётся неизменным. Затем проверяется обновление с установщика 0.1.3, ярлыки, запуск и удаление. Настоящие аккаунты и действующие VPN-подписки в CI не используются.

Изменения изолированы в `desktop-client` и отдельном workflow. Сайт PHP/MySQL и его архивы не изменяются.

## Лицензия

Папка `desktop-client`, патчи и изменённый v2rayN распространяются по GPL-3.0. Уведомления сторонних компонентов сохранены. Исходники из ZIP соответствуют выпускаемой сборке. Эта лицензия не переопределяет лицензии остальных независимых частей репозитория.

«Справка» внизу окна и в меню открывается внутри приложения и описывает все действия; внешняя программа для чтения не запускается.

При нескольких подписках сначала выбирается название в поле «Подписка», затем один из её серверов. Выбор сохраняется; пустая подписка не подставляет серверы других групп.
