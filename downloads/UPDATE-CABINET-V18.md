# v18 — приложение сервиса и страница скачивания

В шапке личного кабинета справа от заголовка появилась кнопка «Скачать приложение сервиса». Она открывает `download.html`: Windows 10/11 x64, Android с неактивной кнопкой «Скоро», инструкции для ПК и временное подключение Android через V2rayTun. Страница доступна без входа. На телефоне кнопка располагается под заголовком.

## Как загрузить обновление на ваш сайт

1. Скачайте `moskompremont-app-download-update.zip` с GitHub и распакуйте его на компьютере.
2. В файловом менеджере хостинга или через FTP откройте папку, где находится ваш `account.html`. Если кабинет открывается по адресу `https://ваш-сайт.ru/account.html`, это корневая папка сайта. Если он находится в подпапке, загрузка выполняется в эту же подпапку.
3. Скопируйте содержимое распакованного архива в эту папку с заменой файлов. Не создавайте дополнительную папку вокруг содержимого архива. `account.html` и новый `download.html` должны лежать рядом.
4. Проверьте, что файлы из папок `assets` и `images` попали в одноимённые папки вашего сайта.
5. Откройте кабинет и нажмите Ctrl+F5. Справа от заголовка нажмите «Скачать приложение сервиса».

Архив меняет только:

- `account.html`;
- `assets/account.css`;
- `download.html`;
- `assets/service-app.css`;
- `assets/service-app.js`;
- `images/service-app-logo.png`.

В архиве также есть эта инструкция. PHP и SQL не меняются. Импортировать базу данных не нужно. Рабочие `private/config.php`, `assets/config.js`, QR-код, пользователи и подписки сохраняются: в небольшом архиве их нет.

## Версия приложения

Кнопка Windows ведёт на установщик МосКомпРемонт из GitHub Releases. Страница проверяет новые выпуски и показывает актуальную версию автоматически. Если проверка недоступна, сохраняется готовая ссылка на проверенный выпуск. При появлении Android нужно будет отдельно добавить его установщик; сейчас кнопка «Скоро» недоступна для нажатия.

В новой Windows-версии кнопка «Справка» внизу окна и в меню ☰ открывает встроенную страницу со всеми кнопками. В приложении версии 0.3.10 можно выбрать «☰ → Проверить обновления приложения» и установить обновление. Либо завершить приложение кнопкой «Выход» и запустить новый установщик поверх прежнего.

## Для установки с более старой версии кабинета

Небольшой архив предназначен для действующего кабинета v17/v17.1. Полный обновлённый комплект — `moskompremont-account-php.zip`; сохраните свои конфиги и QR. Для перехода с v15 требуется миграция `009-client-updates.sql`; для более старого кабинета используйте инструкции соответствующей версии и полный `private/schema.sql`. Само обновление страницы скачивания миграций не добавляет.
