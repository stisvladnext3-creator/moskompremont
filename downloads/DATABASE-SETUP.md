# Как подключить базу пользователей на вашем сервере

Это инструкция для новой установки. При обновлении существующего кабинета используйте UPDATE-CABINET-V5.md: она сохраняет текущие аккаунты и настройки.


Архив предназначен для существующего сайта «МосКомпРемонт»: раздел «Мировой интернет» (internet.html), кабинет (account.html), PHP API и MySQL. Остальные разделы сайта, которых не было в исходном архиве, сюда не добавлялись.

## 1. Подготовьте хостинг

В панели хостинга выберите PHP 8.1 или новее (рекомендуется 8.3+) и включите расширение PDO MySQL (`pdo_mysql`). Нужна MySQL 8+ или MariaDB 10.6+. Включите HTTPS для вашего домена. Сделайте резервную копию сайта.

## 2. Создайте базу и пользователя

В разделе «Базы данных MySQL» создайте отдельную базу, например `moskom_users`, и отдельного пользователя, например `moskom_app`, с надёжным паролем. Панель может автоматически добавить префикс аккаунта к именам: используйте итоговые имена. Сохраните адрес сервера БД (обычно localhost).

Через phpMyAdmin/панель с административными правами импортируйте схему. Рабочему пользователю сайта нужны SELECT, INSERT, UPDATE, DELETE только на эту базу. Права на остальные базы и пользователя root сайту не выдавайте.

Если вы управляете MySQL по SSH, эквивалентные команды (замените пароль перед выполнением):

```sql
CREATE DATABASE moskom_users CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'moskom_app'@'localhost' IDENTIFIED BY 'ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ';
GRANT SELECT, INSERT, UPDATE, DELETE ON moskom_users.* TO 'moskom_app'@'localhost';
```

Пароль БД вводите только в панели хостинга и серверном конфигурационном файле. Он не нужен в браузерном JavaScript.

## 3. Импортируйте таблицы

В phpMyAdmin выберите именно созданную базу → «Импорт» → выберите `private/schema.sql` из архива → выполните импорт. Импорт выполняйте административной учётной записью с правом CREATE. Скрипт создаёт:

- `internet_users` — профили и хеши паролей;
- `internet_orders` — заявки и статусы ручной проверки;
- `internet_rate_limits` — ограничение попыток входа и регистрации.

Либо по SSH: `mysql -u ВАШ_АДМИНИСТРАТОР -p moskom_users < private/schema.sql`. Пароль вводится по запросу, не в командной строке.

## 4. Загрузите файлы

Распакуйте архив в папку существующего сайта, сохраняя пути. Не удаляйте остальные разделы сайта. В полном архиве конфигурация ссылок названа `assets/config.example.js`:

- если `assets/config.js` уже есть на хостинге, сохраните его;
- если это первая установка, скопируйте `assets/config.example.js` в `assets/config.js` и впишите ваши ссылки/контакты;
- `style.css` и остальные общие файлы в полном комплекте взяты из исходного архива: при собственных изменениях сайта используйте архив обновления, а не заменяйте свои стили.

Кнопка «Личный кабинет» добавлена в internet.html. Для действующего сайта, где уже установлены исходные стили и изображения, предпочтителен меньший архив `registration-ozon-php.zip`: он не заменяет общие стили и конфигурацию ссылок.

## 5. Укажите настройки подключения

Скопируйте `private/config.example.php` в `private/config.php` и заполните:

```php
<?php
return [
    'dsn' => 'mysql:host=localhost;dbname=moskom_users;charset=utf8mb4',
    'db_user' => 'moskom_app',
    'db_password' => 'ВАШ_ПАРОЛЬ_БАЗЫ',
    'origin' => 'https://ВАШ-ДОМЕН.ru',
    'secure_cookies' => true,
    'admin_user_ids' => [],
    'qr_image' => '',
    'recipient' => '',
    'payment_note' => 'Укажите время перевода и последние 4 цифры телефона отправителя.',
];
```

`origin` — точный адрес сайта (протокол и домен; порт, если он нестандартный), без пути и завершающего слеша. Для www и без www выберите один основной адрес и настройте перенаправление. Значения `db_user` и `dbname` берите из вашей панели, включая префиксы. Если БД на другом сервере, замените localhost на адрес, который дал хостинг; запись MySQL пользователя должна разрешать соединения именно от вашего веб-сервера.

## 6. Закройте private и проверьте вход

Для Apache уже добавлен `private/.htaccess`. Для Nginx в конфигурации нужного сайта добавьте:

```nginx
location ^~ /private/ { deny all; }
```

Если сайт находится в подпапке, добавьте её в путь. После изменения Nginx проверьте конфигурацию `nginx -t` и примените её. Предпочтительно вынести config.php за пределы публичного каталога и задать полный путь через серверную переменную INTERNET_CONFIG. После импорта удалите публичную копию schema.sql. Убедитесь, что обращение к `/private/schema.sql` возвращает 403 или 404.

Откройте `https://ВАШ-ДОМЕН.ru/account.html`, зарегистрируйтесь, выйдите и войдите снова. Новый профиль должен появиться в internet_users. Поле password_hash должно содержать хеш, а не исходный пароль.

Почта пока используется как логин/контакт: подтверждение по письму и восстановление пароля не подключены. Их нужно добавить перед полноценным публичным запуском с самостоятельным восстановлением доступа.

## 7. Назначьте администратора

Найдите ID своей записи в internet_users и лично проверьте, что это ваша учётная запись. В config.php укажите этот номер в `admin_user_ids`, например `[7]`, если ваш ID — 7. Обновите кабинет: появится блок «Проверка оплат». Публичная регистрация сама по себе не даёт административных прав.

## 8. Подключите QR Озон Банка

Положите настоящий QR для приёма платежей в `images/payment/ozon-qr.png`. Укажите в config.php `qr_image` = `images/payment/ozon-qr.png`, а в `recipient` — имя получателя так, как оно отображается при переводе. Сверьте QR, получателя и сумму в приложении банка. Пока QR и имя не настроены, создание заявок на оплату отключено.

Клиент выбирает тариф → оплачивает → отправляет заявку «Я оплатил». Вы проверяете поступление в Озон Банке и подтверждаете его в кабинете администратора. Подписку выдаёте отдельно; банковского API и автоматического продления в этом архиве нет.

## Если не работает

- «Кабинет ещё не настроен» — нет private/config.php или неверный INTERNET_CONFIG.
- «Сервис временно недоступен» — проверьте DSN, пароль БД, pdo_mysql, импорт таблиц и серверный PHP error log. Не включайте публичный показ технических ошибок.
- «Недопустимый источник запроса» — origin отличается от адреса открытой страницы (www, https или порт).
- После входа снова форма — проверьте HTTPS, серверное хранение PHP-сессий и cookie. Secure cookie не работает через обычный HTTP; не отключайте secure_cookies на публичном сайте.
- Оплата недоступна — проверьте наличие изображения, точность пути и заполненное имя получателя.


После базовой установки настройте SMTP, загрузите CSV подписок и включите cron отправки писем по UPDATE-CABINET-V2.md. Текущий schema.sql уже включает таблицы подписок, обращений и уведомлений.


Для фото включите PHP fileinfo; лимиты и снятие привязки описаны в UPDATE-CABINET-V3.md. Текущий schema.sql включает все таблицы v3.


Для ручного назначения подписок без оплаты см. UPDATE-CABINET-V4.md. После установленной v3 для v4 не требуется менять структуру базы.


Для отдельных ключей роутеров в v5 импортируйте новую таблицу из private/migrations/004-router-keys.sql или полный schema.sql. Существующие данные сохраняются; настройка — в UPDATE-CABINET-V5.md.
