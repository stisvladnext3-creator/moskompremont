# v5: отдельные ключи для роутеров

Добавлен отдельный тип выдачи: ключи и текстовые конфигурации для роутеров. Они хранятся отдельно от подписочных ссылок и не участвуют в поиске подписок по названию.

## Установка поверх v4

1. Сделайте резервную копию базы и файлов сайта. Сохраните свой private/config.php, assets/config.js и QR-код.
2. Посмотрите имя базы после dbname= в dsn вашего config.php. В phpMyAdmin/панели выберите именно эту базу.
3. Импортируйте **private/migrations/004-router-keys.sql**. Добавится только таблица internet_router_keys, текущие пользователи, подписки, ключи и оплаты не удаляются. Повторный импорт этого скрипта не очищает таблицу.
4. Загрузите файлы обновления в папку сайта, сохраняя пути. Кроме обновлённых account.html, assets/account.js, assets/account.css, api/account.php и private/runtime.php нужны новые **private/router-keys.php** и **api/router-key.php**.
5. Обновите страницу кабинета через Ctrl+F5.

Если устанавливаете с нуля, обновляете более раннюю версию или отсутствуют предыдущие таблицы, импортируйте полный **private/schema.sql** из нового архива. Он создаёт отсутствующие таблицы через CREATE TABLE IF NOT EXISTS и сохраняет имеющиеся записи. При ошибке Failed to open the referenced table internet_users сначала сверьте выбранную базу с config.php. Удалять базу или отключать внешние ключи не нужно.

Новых паролей, почтовых параметров, расширений PHP или прав записи в папки для ключей не требуется. Используются текущие PHP-сессии, PDO MySQL, администраторские ID и существующая база. Свою рабочую конфигурацию не заменяйте примером.

## Выдать ключ клиенту без оплаты

1. Админка → **«Ключи роутеров»**.
2. Найдите клиента по имени, почте, Telegram или ID и выберите его в «Получателе ключа».
3. Укажите понятное название, например «Домашний роутер» или «Роутер на даче». Название может содержать пробелы, кириллицу и эмодзи, до 100 символов.
4. Выберите формат:
   - «Ключ подключения» — одна строка, например vless://, vmess://, ss:// или другой готовый текстовый ключ;
   - WireGuard — многострочная конфигурация с возможностью скачать .conf;
   - OpenVPN — текст конфигурации с возможностью скачать .ovpn;
   - «Текстовый ключ / конфигурация» — другой многострочный текст, скачивается как .txt.
5. Вставьте готовый ключ или конфигурацию, до 64 КБ.
6. Нажмите **«Выдать ключ клиенту»**.

При необходимости повторите для других ключей: одному клиенту можно выдать несколько отдельных ключей для разных роутеров. Выдача не требует заявки на оплату и не создаёт фиктивный платёж.

В разделе «Новые пользователи» у каждого клиента есть кнопка **«Выдать ключ роутера»**. Она открывает форму с уже выбранным получателем. Подписки по-прежнему назначаются отдельно своей кнопкой.

Сайт хранит и передаёт вставленные данные. Он не генерирует VPN-ключи, не подключает роутер и не проверяет работоспособность конфигурации у провайдера: вставляйте подготовленные вами рабочие значения.

## Как клиент получает ключ

В кабинете клиента есть отдельная вкладка **«Ключи для роутера»**. Для каждого ключа отображаются название, формат и кнопки:

- «Показать ключ» — открывает текст;
- «Скопировать ключ» — копирует значение целиком;
- «Скачать .txt/.conf/.ovpn» — сохраняет файл.

Значение ключа и переносы строк сохраняются в базе. Скачивание возвращает исходное содержимое; для сравнения дубликатов игнорируются пробелы по краям и различие CRLF/LF. Кнопки «Открыть как подписку» для отдельных ключей нет.

После выдачи клиенту нужно обновить список ключей кнопкой «Обновить» либо обновить страницу. Подписочные ссылки остаются во вкладке «Мои подписки».

## Привязки и защита

- Ключ доступен только назначенному клиенту и администратору, в том числе при обращении напрямую к API или адресу скачивания.
- Списки содержат только метаданные. Само значение запрашивается после нажатия «Показать»/«Скопировать» или при скачивании.
- Один и тот же текст ключа повторно этому же клиенту не дублируется. Такой же текст, уже закреплённый за другим клиентом, не выдаётся без предварительного снятия его привязки.
- В «Базе ключей для роутеров» есть кнопка **«Снять привязку ключа»**. Она убирает доступ прежнему клиенту, сохраняя запись в базе. Можно затем нажать «Выдать ключ клиенту» у свободной записи и выбрать нового получателя.
- Запрос из устаревшей вкладки не снимет уже изменившуюся привязку у нового владельца.
- Поиск или регистрация с названием подписки не выдаёт отдельные ключи для роутеров. Их назначает только администратор.
- В журнал попадают название ключа, ID клиента и действие, без содержимого. Ключи не отправляются по почте и не попадают в публичные файлы.

Снятие привязки в кабинете не отключает уже скопированный ключ во внешней VPN-системе. Для прекращения его работы отключите/перевыпустите ключ там.

## Что сохраняется

Предыдущие подписочные ссылки, ручная выдача без оплаты, платежи, переписка с фото и настройки SMTP остаются на месте. Добавляется одна таблица, текущие таблицы не переделываются. В архиве нет реальных клиентских ключей и паролей.
