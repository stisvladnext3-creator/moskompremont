# Обновление v11 — обновление подписки, выбор сервера и настройка Podkop

На главную страницу и в личный кабинет добавлены три отдельных руководства:

1. **V2RayN — обновление списка серверов подписки:** Subscription Group → Update current subscription without proxy. Для наглядности используется уже загруженный скриншот этого меню из предыдущего архива.
2. **V2RayN — переключение сервера:** правая кнопка мыши по нужному серверу → Set as active.
3. **Роутер OpenWrt / Podkop — замена ссылки:** подключение к Wi-Fi, адрес 192.168.31.1, вход через Login, Services → Podkop, поле «URL прокси» в «Секциях», замена ссылки, Save & Apply, «Диагностика» и «Запустить диагностику».

В руководстве роутера последовательная нумерация 1–9, без повторяющегося шага 7. Русское название Save & Apply — «Сохранить и применить». В кабинете есть пояснение, где взять выданную ссылку для роутера, и кнопка «Ключи для роутера» в начале раздела инструкций.

В стандартном каталоге теперь 11 руководств. Прежние 17 изображений сохранены; скриншот меню V2RayN также используется в отдельном руководстве обновления. Три новых изображения из последних сообщений доступны только для просмотра в чате и пока не были получены как файлы. Поэтому новое изображение с красной/оранжевой рамками ещё не заменяет прежний снимок, а руководства переключения сервера и Podkop пока содержат текст. Ссылок на отсутствующие файлы в этой сборке нет.

## Установка поверх v8, v9 или v10

1. Сделайте копию файлов сайта.
2. Распакуйте `moskompremont-cabinet-v11-update.zip` и загрузите содержимое в папку с `account.html` и `internet.html`, с заменой файлов и сохранением структуры папок.
3. Загрузите и HTML, и `assets/account.js`, и `assets/instructions.js`, чтобы новая кнопка кабинета работала.
4. Свои `private/config.php`, `assets/config.js` и QR-код сохраните: архив обновления их не содержит.
5. Обновите страницу через Ctrl+F5 и проверьте новые руководства.

**Для установленной v8–v10 импорт SQL и переустановка службы Ubuntu не требуются.** Серверный код, база и служба не менялись. Архив содержит все предыдущие изменения кабинета и инструкции со скриншотами из последнего RAR.

Для установленной v5–v7 импортируйте `private/migrations/005-monitoring.sql`; для более ранней версии или новой установки — полный `private/schema.sql`. Установка службы и настройка почты описаны в `MONITORING-SETUP.md`.

Общий каталог обеих страниц — `assets/instructions.js`; `INSTRUCTIONS.json` — копия каталога для просмотра. Новые руководства добавляются и к пользовательскому `SITE_CONFIG.instructions` без дублирования совпадающих ID/заголовков.
