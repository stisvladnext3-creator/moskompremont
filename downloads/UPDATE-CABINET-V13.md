# Обновление v13 — персональная вкладка Keenetic

Вкладка **Keenetic** появляется только у клиентов, которым администратор включил её галочкой. Внутри — файлы конфигурации для их роутеров с кнопками скачивания. У одного клиента может быть несколько файлов.

## Установка поверх v8–v12

1. Скачайте `moskompremont-cabinet-v13-update.zip` и распакуйте на компьютере. Сделайте резервную копию файлов сайта и текущей базы MySQL.
2. Откройте панель хостинга → базы данных → **phpMyAdmin**. Слева выберите именно базу кабинета: её название указано после `dbname=` в строке `dsn` вашего `private/config.php`.
3. В выбранной базе откройте **Импорт → Выберите файл**. В распакованном обновлении выберите **`private/migrations/006-keenetic.sql`**, затем нажмите «Вперёд» / «Импорт». Появятся таблицы `internet_keenetic_access` и `internet_keenetic_files`. Существующие аккаунты, подписки, ключи и оплаты сохраняются. Этот SQL можно импортировать повторно.
4. Через файловый менеджер хостинга или FTP загрузите **содержимое** распакованного обновления в папку сайта, где лежит `account.html`, с заменой файлов и сохранением папок. Не создавайте дополнительную папку вокруг обновления.
5. Сохраните свои `private/config.php`, `assets/config.js` и QR-код. Архив обновления не содержит и не заменяет их. Доступ извне к `private` должен оставаться закрытым существующим `.htaccess` или настройкой Nginx из DATABASE-SETUP.md.
6. Откройте `https://moskompremont.ru/account.html`, нажмите **Ctrl+F5** и войдите администратором.

Если установлена **v7 или старше** либо это новая установка, вместо отдельного `006-keenetic.sql` импортируйте полный **`private/schema.sql`**: он создаёт недостающие таблицы в правильном порядке. При новой установке сначала создайте MySQL-базу и заполните `private/config.php` по DATABASE-SETUP.md. Ничего удалять из действующей базы не нужно.

Переустановка службы мониторинга Ubuntu и изменение SMTP не требуются. Если SQL ещё не импортирован, прежние разделы кабинета продолжают работать, а управление Keenetic подскажет нужный файл миграции.

## Как включить клиенту

1. **Админка → Клиенты**.
2. Найдите клиента по имени, почте, Telegram / телефону или ID.
3. Поставьте галочку **«Показывать вкладку Keenetic»**. Изменение сохраняется сразу; дождитесь сообщения об успешном включении.
4. Нажмите **«Файлы Keenetic»** рядом с этим клиентом. Откроется раздел с выбранным получателем.
5. Проверьте имя и почту, выберите файлы и нажмите **«Загрузить файлы клиенту»**.

Можно сначала загрузить файлы при выключенной галочке, а затем включить доступ. Та же галочка есть в **Админка → Keenetic**: здесь можно найти и выбрать любого зарегистрированного клиента.

Клиент увидит вкладку после обновления кабинета; в уже открытом кабинете доступ проверяется примерно каждые 20 секунд, пока окно видно. Прямая ссылка для клиента с доступом: **https://moskompremont.ru/account.html#keenetic**.

## Файлы и отключение доступа

- До **3 файлов за одну загрузку**, каждый непустой и не больше **5 МБ**. Повторная загрузка добавляет новые файлы к существующим.
- Форматы: `.conf`, `.ovpn`, `.cfg`, `.config`, `.json`, `.txt`, `.yaml`, `.yml`, `.zip`. Загружайте готовую конфигурацию, подходящую клиентскому роутеру; сайт передаёт файл без преобразований. ZIP не распаковывается.
- **«Удалить файл»** удаляет выбранную конфигурацию из кабинета после подтверждения. Другие файлы клиента сохраняются. Для замены загрузите новую версию и удалите старую.
- Снятая галочка скрывает вкладку и сразу закрывает клиенту скачивание, включая прежние прямые ссылки. Файлы остаются в базе: при повторном включении они снова доступны.
- Содержимое хранится в MySQL, без открытой папки загрузок. Каждое скачивание проверяет активный вход, владельца файла и включённый доступ. Администратор может скачивать и удалять файлы при выключенной вкладке клиента. Другие клиенты их не получают.
- Подписки и прежний раздел «Ключи для роутера» работают отдельно и сохраняются.

Если хостинг отклоняет загрузку, задайте в настройках PHP сайта **`upload_max_filesize = 5M`** и **`post_max_size = 20M`**, затем повторите. Если файлы отклоняет Nginx до запуска PHP, установите для сайта `client_max_body_size 20m` или попросите поддержку хостинга увеличить лимит.
