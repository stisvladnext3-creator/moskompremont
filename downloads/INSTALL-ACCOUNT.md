# Кабинет МосКомпРемонт — текущая версия v12

Начните с UPDATE-CABINET-V12.md. Клиентам добавлена вкладка «Статус серверов» с результатами действующего мониторинга. В инструкции обновления подписки, переключения сервера V2RayN и настройки OpenWrt/Podkop добавлены все 3 оригинальных скриншота из instr.rar. Каталог содержит 11 руководств и 20 изображений.

После установленной v8–v11 достаточно загрузить файлы обновления с заменой, включая assets и images/instructions, и обновить страницу через Ctrl+F5. Импорт SQL и переустановка службы Ubuntu не требуются. Для v5–v7 импортируйте private/migrations/005-monitoring.sql в текущую базу из private/config.php. Для v4 и старше или новой установки используйте полный private/schema.sql: он создаёт недостающие таблицы и сохраняет записи.

Установка Ubuntu-службы и настройка Яндекс Почты — в MONITORING-SETUP.md. Администратор задаёт подписку для мониторинга в «Серверы», а клиенты видят только названия и результаты. При выключенном мониторинге или отсутствии свежих проверок кабинет показывает соответствующее состояние.

Сохранены список клиентов с привязанными подписками и ключами, удаление ключей, фоновая обработка и диагностика почты, пароль от 6 символов, поле «Telegram / номер телефона», ручная выдача подписок и ключей, импорт CSV, оплата и поддержка с фотографиями.

Требуются PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. PHPMailer включён с лицензией. Для Ubuntu-службы — SSH с sudo/root, Python 3.8+, curl и Xray из 3x-ui.

Свои private/config.php, assets/config.js и QR-код сохраните на сервере: архив обновления их не содержит. Реальных паролей, подписки для мониторинга и клиентской базы в исходниках нет.
