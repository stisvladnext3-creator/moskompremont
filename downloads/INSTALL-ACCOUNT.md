# Кабинет МосКомпРемонт — текущая версия v14

Начните с **UPDATE-CABINET-V14.md**. Добавлено общее объявление на странице «Мировой интернет», над публичным списком серверов и во вкладке «Статус серверов» в кабинете. Первый импорт включает сообщение о работе через Wi-Fi и сбое / ограничении на мобильной связи.

**Для обновления v13 импортируйте `private/migrations/007-service-notice.sql` в действующую базу из private/config.php**, затем загрузите файлы обновления с заменой и обновите браузер через Ctrl+F5. Для v8–v12 импортируйте также `006-keenetic.sql`; для v7 и старше или новой установки используйте полный `private/schema.sql`. Данные сохраняются. Повторный импорт не заменяет отредактированное объявление и не включает скрытое.

Изменение и скрытие: **Админка → Объявление → текст и галочка показа → Сохранить объявление**. Снятая галочка сохраняет текст для следующего включения. Открытые страницы обновляют его примерно раз в минуту. Объявление отображается независимо от включения мониторинга.

Свои `private/config.php`, `assets/config.js` и QR-код сохраните на сервере: обновление их не содержит. Папка private должна оставаться закрытой извне. Рабочие пароли, VPN-конфигурации, источник мониторинга и клиентская база в исходники не включены.

Сохранены Keenetic с приватными файлами клиентов, 11 инструкций и 20 изображений, подписки и ключи, список клиентов, оплата, поддержка с фото, почта и мониторинг. Службу Ubuntu и SMTP менять не требуется; их настройка описана в MONITORING-SETUP.md.

Требования: PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. Для загрузок файлов: upload_max_filesize=5M, post_max_size=20M. Первичная установка базы — в DATABASE-SETUP.md.
