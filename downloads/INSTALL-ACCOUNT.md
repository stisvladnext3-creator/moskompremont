# Кабинет МосКомпРемонт — текущая версия v6

Начните с UPDATE-CABINET-V6.md: пароль от 6 символов, поле «Telegram / номер телефона». При переходе с v5 импорт SQL не требуется.

При переходе с v4 импортируйте private/migrations/004-router-keys.sql в ту же базу, которая указана в config.php, затем загрузите файлы. Для новой установки или более старой версии используйте полный private/schema.sql. Скрипты создают недостающие таблицы и не очищают текущие записи.

Возможности: несколько подписок и ключей у клиента, ручная выдача без оплаты или после её подтверждения, импорт CSV подписок, снятие привязки, приватная переписка с фото и уведомления администратора.

Для SMTP и CSV — UPDATE-CABINET-V2.md; для фото и снятия привязки подписок — UPDATE-CABINET-V3.md; для прямого назначения подписок — UPDATE-CABINET-V4.md; для отдельных ключей — UPDATE-CABINET-V5.md. Требования PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. PHPMailer включён с лицензией.

Сохраняйте свои private/config.php, assets/config.js и QR-код — в архиве обновления их нет. Настоящие пароли и клиентская база в исходники не входят.
