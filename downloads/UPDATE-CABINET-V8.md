# Обновление v8 — серверы, клиенты, ключи и почта

## Что добавлено

- **Админка → Серверы:** одна закрытая HTTPS-ссылка-подписка, токен для службы Ubuntu и отдельная внешняя проверка основного сервера.
- На странице `internet.html` — реальные результаты проверки каждого подключения: состояние, число вида **258 мс** и время проверки. Без действующей службы данные не подменяются демонстрационными значениями.
- **Админка → Клиенты:** общий список всех пользователей, поиск и страницы по 100 записей. У каждого видны контактные данные, названия текущих подписок и ключей для роутеров. Содержимое ключей в этот список не входит. Из карточки доступны назначение подписок и выдача ключа.
- **Удаление ключей:** в «Ключи роутеров» появилась кнопка «Удалить ключ». Она удаляет запись из базы кабинета и убирает её у клиента; отменяется перед удалением обычным диалогом подтверждения. При изменившемся владельце требуется обновить список. Удаление из кабинета не отключает уже скопированный ключ во внешней VPN-системе: при необходимости отключите его в 3x-ui отдельно.
- **Почта:** последние письма, понятные ошибки SMTP и время последней обработки. Служба Ubuntu автоматически обрабатывает очередь независимо от включения мониторинга; cron на PHP-хостинге остаётся альтернативой.

Инструкции в личном кабинете, пароль от 6 символов, поле «Telegram / номер телефона», поддержка с фото и прежние подписки сохранены.

## Установка

1. Сделайте резервную копию файлов и базы.
2. Загрузите содержимое `moskompremont-cabinet-v8-update.zip` в папку сайта с заменой файлов, сохраняя структуру.
3. Для установленной v5–v7 импортируйте **private/migrations/005-monitoring.sql** в существующую базу. Для более старой версии или новой установки — полный **private/schema.sql**. Новая таблица не удаляет пользователей, подписки, ключи, оплаты, переписку и очередь писем.
4. Свои `private/config.php`, `assets/config.js` и QR-код сохраните на сервере — в архиве обновления их нет.
5. Обновите кабинет через Ctrl+F5. «Клиенты», удаление ключей и диагностика почты работают после обновления файлов/таблицы.
6. Для фоновых проверок и обработки писем установите Ubuntu-службу по **MONITORING-SETUP.md**. API и пароль панели 3x-ui не требуются.

Отдельный архив службы: **moskompremont-monitor-ubuntu-v8.zip**. Подробная инструкция рассчитана на https://moskompremont.ru/internet.html и SSH с sudo. Ссылку-подписку вводите только в настоящей админке сайта, токен — в установщике Ubuntu. Предпросмотр показывает явно отмеченные демонстрационные результаты и не отправляет письма.

На вашем сервере файлы и службу устанавливает владелец: архивы не меняют действующий хостинг автоматически. Фактическая доставка на Яндекс требует действующего SMTP-пароля приложения и доступного SMTP-порта; причины видны в «Почте».
