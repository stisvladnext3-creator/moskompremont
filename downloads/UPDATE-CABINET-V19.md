# Android-приложение и страница скачивания

На странице «Скачать приложение сервиса» появилась версия МосКомпРемонт VPN для Android 7 и новее: прямая ссылка на APK и инструкция. Приложение использует тот же личный кабинет сайта, раздельный выбор подписок и серверов, статус сервиса, Russia, DNS, проверку доступности, обновления и встроенную справку.

1. Скачайте `moskompremont-app-download-update.zip` из выпуска Android на GitHub и распакуйте.
2. В файловом менеджере хостинга откройте папку, где сейчас лежит `account.html` сайта moskompremont.ru.
3. Загрузите содержимое архива в эту папку с заменой одноимённых файлов. Папку `assets` и `images` объедините с существующими. `download.html` должен лежать рядом с `account.html`.
4. Откройте `https://moskompremont.ru/download.html` и обновите страницу без кеша. Кнопка Android должна скачивать APK, а Windows — установщик для ПК.

Базу данных импортировать не требуется. Архив не содержит настроек подключения к БД, клиентских подписок, QR-кода и паролей; существующий `private/config.php` сохраняется.

APK скачивается из постоянного публичного выпуска GitHub. Страница дополнительно проверяет новые выпуски и выбирает последнюю версию отдельно для Windows и Android. Если проверка временно недоступна, остаются рабочие прямые ссылки, включённые в страницу.

Для проверки клиентом: установите APK, подтвердите установку из текущего браузера, откройте приложение, войдите с почтой и паролем сайта. Выберите подписку, затем сервер и нажмите «Включить VPN». Первый запуск требует системного разрешения Android. Обновления устанавливайте поверх прежней версии.

Публикация файлов на основном PHP-хостинге выполняется загрузкой этого архива. Предпросмотр в ChatGPT — отдельная страница для проверки оформления.
