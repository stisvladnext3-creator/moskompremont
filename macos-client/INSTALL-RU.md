# МосКомпРемонт VPN для Mac

Два варианта с одинаковым интерфейсом и функциями:
- **legacy** — macOS 11 Big Sur и macOS 12 Monterey; совместимый .NET 8 и ядра для старой macOS.
- **modern** — macOS 13 Ventura и новее; .NET 10 и современные ядра.

Для каждого есть **osx-x64** (Intel) и **osx-arm64** (Apple M1/M2/M3/M4/M5). Тип процессора смотрите в меню Apple → «Об этом Mac».

1. Скачайте DMG для вашей macOS и процессора.
2. Откройте образ и перетащите **MoskomVPN.app** в **Программы / Applications**.
3. Запустите приложение из «Программ». Это независимая сборка без сертификата Developer ID / нотариального заверения Apple. macOS может потребовать подтверждение запуска через «Открыть» или настройки безопасности. Проверяйте источник и SHA256SUMS из того же релиза; защиту системы отключать не требуется.
4. Войдите в кабинет с почтой и паролем сайта или скопируйте ссылку и нажмите **+**. При нескольких подписках сначала выберите подписку, затем нужный сервер.
5. Выберите маршрутизацию и нажмите большую кнопку включения. Если macOS запросит разрешение на изменение настроек сети, подтвердите его. При отказе приложение не должно показывать успешное подключение.

Вход сохраняется в **Связке ключей / Keychain**, пароль не сохраняется. На первом запуске после замены независимой сборки Keychain может попросить разрешение на доступ к ранее сохранённому входу.

В меню ☰: управление вручную добавленными подписками, обновление Russia, проверка версии приложения, DNS (автоматический / 1.1.1.1 / 8.8.8.8 / 9.9.9.9 / свой адрес), справка и выход. Пресет Russia и геоданные входят в комплект.

- **Всё** — весь обрабатываемый прокси трафик идёт через VPN.
- **Всё, кроме РФ** — российские сервисы идут напрямую, остальные через VPN.
- **Заблокированное** — через VPN идут сервисы из списков блокировок, российские сервисы работают напрямую.

Режим подключения — **системный прокси macOS**, как системный прокси в Windows-версии. Программы, игнорирующие системный прокси, и весь UDP-трафик устройства этим режимом не охватываются. TUN в упрощённом интерфейсе не заявляется. Скорость и доступность зависят от маршрута и серверов.

При выключении VPN и выходе возвращаются прежние настройки прокси. Отдельный процесс следит за аварийным завершением приложения и пытается восстановить их; после перезагрузки незавершённая операция проверяется при запуске. Изменения, внесённые другой программой после подключения, не перезаписываются.

Обновление приложения: ☰ → «Проверить обновления приложения» → «Обновить сейчас». Приложение скачает образ правильного варианта и процессора, проверит SHA-256, завершит VPN и откроет образ. Перетащите новую версию в «Программы» с заменой и запустите её. Данные в `~/Library/Application Support/MosKomRemontVPN` сохраняются; Keychain может запросить доступ после обновления. Не запускайте обе версии одновременно.

«Проверить доступность» измеряет выбранное подключение с вашего Mac. «Статус сервиса» показывает центральный мониторинг и объявление сайта. Результаты могут различаться. Кабинет синхронизирует активные подписки, их обновления и сроки; ручные подписки сохраняются при выходе из кабинета.
