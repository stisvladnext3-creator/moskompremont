# Проверка macOS

Сборка включает общий интерфейс и логику Windows 0.3.17 на основе v2rayN 7.25.6. Два профиля: legacy (.NET 8, macOS 11+) и modern (.NET 10, macOS 13+); отдельные пакеты Intel x64 / Apple Silicon arm64.

GitHub macOS runners проверяют запуск настоящего интерфейса, импорт, кабинет с тестовым сервером, хранение сессии в Keychain, синхронизацию/смену/отзыв/истечение подписок, изоляцию списка серверов, маршрутизацию, DNS, обновления, справку, управление подписками и неизменность подписанного application bundle. Системный прокси во время общего UI-теста не меняется.

Отдельный тест на изолированном macOS runner проверяет настоящие SystemConfiguration proxy preferences: применение, точное восстановление и восстановление после принудительного завершения родителя. Этот тест выполняется как root, чтобы не автоматизировать диалог ввода пароля macOS. В обычном приложении используются Authorization Services и системное разрешение пользователя.

Каждый доставляемый Mach-O файл проверяется по архитектуре и собственным deployment-командам: legacy не может содержать бинарник с минимальной macOS выше 11.0, modern — выше 13.0. Заголовки бинарников не исправляются для обхода несовместимости. Ядра проверяют конфигурации DNS/Russia; DMG проходит hdiutil verify, приложение — codesign verify. Подпись ad-hoc, Developer ID и нотариального заверения Apple нет.

Физический Mac пользователя и запуск именно в macOS 11/12 не проверялись. Статическая проверка deployment target не заменяет испытание на Big Sur. На CI используется доступная современная macOS. Реальные клиентские пароли/подписки и внешние VPN-серверы в тестах не используются. Перед массовым использованием старой сборки нужна проверка подключения и системного запроса разрешения на вашем Mac.
