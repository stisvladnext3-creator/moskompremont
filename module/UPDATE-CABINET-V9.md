# Обновление v9 — новые инструкции V2RayN и V2rayTun

Добавлены три руководства на главную страницу и во вкладку «Инструкции» личного кабинета:

1. **V2RayN — импорт подписки из буфера обмена.** Копирование ссылки, Configuration → Import Share Links from clipboard, выбор import_sub, Subscription Group → Update current subscription without proxy. На скриншоте Configuration находится слева вверху; направление исправлено в тексте.
2. **V2rayTun — добавление ссылки.** Копирование выданной ссылки, «+» справа вверху, «Импорт из буфера обмена».
3. **V2rayTun — удаление подписки из приложения.** Долгое нажатие на название группы подписки, затем «Удалить».

В кабинете первый шаг объясняет копирование из «Моих подписок». В стандартном каталоге теперь 8 руководств. Прежние 5 инструкций и их 9 скриншотов сохранены. Новые руководства этой сборки содержат текст: оригиналы новых скриншотов не были доступны как файлы для включения в архив. Ссылок на отсутствующие изображения нет.

## Установка поверх v8

1. Сделайте копию файлов сайта.
2. Распакуйте `moskompremont-cabinet-v9-update.zip` и загрузите содержимое в папку с `account.html` и `internet.html`, разрешив замену файлов.
3. Сохраните свои `private/config.php`, `assets/config.js` и QR-код: их в архиве нет.
4. Обновите страницу через Ctrl+F5 и откройте «Инструкции».

**После установленной v8 импорт SQL и переустановка службы Ubuntu не требуются.** Серверный код и схема базы не менялись. Мониторинг, клиенты, удаление ключей, почта, оплаты и поддержка работают по прежним настройкам.

Если v8 ещё не установлена: для v5–v7 импортируйте `private/migrations/005-monitoring.sql`; для более ранней версии или новой установки используйте полный `private/schema.sql`. Настройка службы и почты — в `MONITORING-SETUP.md`; служба остаётся версии v8.

## Каталог

Общее содержание обеих страниц — `assets/instructions.js`; `INSTRUCTIONS.json` — копия каталога для просмотра. Новые руководства также добавляются к пользовательскому `SITE_CONFIG.instructions`. Запись с совпадающим ID или заголовком используется без дублирования, так что ваши изменения текста сохраняются.
