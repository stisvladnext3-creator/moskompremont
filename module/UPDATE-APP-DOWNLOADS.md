Обновление страницы скачивания МосКомпРемонт

1. Откройте файловый менеджер вашего хостинга и папку, где уже находятся account.html и download.html.
2. Скопируйте download.html и account.html с заменой. Файлы из assets положите в существующую папку assets, также с заменой файлов. Сохраните структуру папок из архива.
3. Откройте https://moskompremont.ru/download.html?v=23 и обновите страницу без кеша. На ней должны быть Windows 0.3.35, Android 0.1.29, macOS 0.2.24 (две версии системы, в каждой Intel и Apple Silicon).

Базу данных импортировать не нужно. private/config.php, QR-код, пользователей и подписки эта поставка не изменяет. В account.html добавлен показ/скрытие пароля при входе и регистрации. Скрипт проверяет более новые проверенные релизы GitHub, а при недоступности API сохраняет рабочие резервные ссылки.

Windows устанавливайте поверх прежней версии. Android APK подписан прежним ключом: устанавливайте обновлением, без удаления приложения. Для Mac выберите систему 11–12 (legacy) либо 13+ (modern) и свой процессор, затем перетащите приложение из DMG в «Программы». Новые режимы: сначала отметьте пункты в ☰ → «Приложения»/«Сервисы», затем выберите одноимённую маршрутизацию. На ПК потребуется системное разрешение администратора.

Запуск на физическом Mac с macOS11/12 не проверялся; нативная совместимость файлов проверена, приложение и сетевые функции проверены на современной macOS.
