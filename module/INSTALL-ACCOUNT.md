# МосКомпРемонт: кабинет с подписками и поддержкой

При обновлении уже работающего сайта начните с **UPDATE-CABINET-V2.md**. Нужно импортировать private/migrations/002-cabinet.sql, загрузить файлы и добавить SMTP-настройки в свой config.php. Существующий config.php, assets/config.js и банковский QR сохраняйте.

Для установки с нуля следуйте **DATABASE-SETUP.md**, импортировав private/schema.sql: он уже содержит все таблицы версии 2. Затем настройте администратора, почту и импорт подписок по UPDATE-CABINET-V2.md.

PHP 8.1+ с pdo_mysql, openssl и сессиями; MySQL 8+ / MariaDB 10.6+; HTTPS. PHPMailer 7.2.0 включён в private/vendor с лицензией, устанавливать Composer не нужно.

Рабочие данные пользователей, ссылки подписок и пароли не включены в архив. Подписки загружаются администратором CSV-файлом в базу. У одного клиента может быть несколько ссылок. Новые подписки выдаются вручную после подтверждения оплаты; старые — по указанным клиентом названиям, как выбрано владельцем.

Почта уведомлений: sania.iwannikow@yandex.ru. Реальная отправка требует настройки SMTP на вашем хостинге. Пока она не настроена, письма остаются в очереди, а уведомления видны в кабинете.
