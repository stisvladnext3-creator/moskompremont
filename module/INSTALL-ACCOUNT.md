# Кабинет МосКомпРемонт — текущая версия v4

Для перехода с v3 загрузите обновление и выполните Ctrl+F5. **Изменений структуры базы нет, SQL импортировать повторно не нужно.** Начните с UPDATE-CABINET-V4.md.

При переходе с более ранней версии или установке с нуля импортируйте полный private/schema.sql в базу из config.php. Он создаёт отсутствующие таблицы, не удаляя текущих пользователей, подписки, переписку или оплаты.

Возможности: несколько подписок у клиента, ручная выдача без оплаты или после подтверждения оплаты, импорт CSV, снятие привязки, приватная переписка с фото и уведомления администратора.

Для SMTP и CSV смотрите UPDATE-CABINET-V2.md; для приватных фото и снятия привязки — UPDATE-CABINET-V3.md; для прямого назначения клиенту — UPDATE-CABINET-V4.md. Требования PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. PHPMailer включён с лицензией.

Сохраняйте свои private/config.php, assets/config.js и QR-код — в архиве обновления их нет. Пароли и реальная клиентская база не входят в исходники и архивы.
