# Кабинет МосКомпРемонт — текущая версия v10

Начните с UPDATE-CABINET-V10.md: к инструкциям V2RayN и V2rayTun добавлены все 8 скриншотов из архива владельца. Они доступны на главной и в личном кабинете, с подписями по шагам и открытием в полном размере.

После установленной v8/v9 достаточно загрузить файлы обновления, включая images/instructions, с заменой и обновить страницу через Ctrl+F5. Импорт SQL и переустановка службы Ubuntu не требуются.

Для v5–v7 импортируйте private/migrations/005-monitoring.sql в текущую базу из private/config.php. Для v4 и старше или новой установки используйте полный private/schema.sql: он создаёт недостающие таблицы и сохраняет записи. Установка Ubuntu-службы и настройка Яндекс Почты — в MONITORING-SETUP.md.

Сохранены мониторинг подписки, список клиентов с привязанными подписками и ключами, удаление ключей, фоновая обработка почты и её диагностика. Также доступны пароль от 6 символов, поле «Telegram / номер телефона», несколько подписок и ключей у клиента, ручная выдача с оплатой и без неё, импорт CSV, поддержка с фотографиями и инструкции в кабинете.

Требуются PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. PHPMailer включён с лицензией. Для Ubuntu-службы — SSH с sudo/root, Python 3.8+, curl и Xray из 3x-ui.

Свои private/config.php, assets/config.js и QR-код сохраните на сервере: архив обновления их не содержит. Реальных паролей, подписки для мониторинга и клиентской базы в исходниках нет.
