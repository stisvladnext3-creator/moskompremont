# Кабинет МосКомпРемонт — текущая версия v17

Обновление v17: [UPDATE-CABINET-V17.md](UPDATE-CABINET-V17.md) — массовая замена домена/IP в базе подписок. Поверх v16 импорт SQL не нужен.

Обновление с действующего кабинета: [UPDATE-CABINET-V16.md](UPDATE-CABINET-V16.md). Для v15 нужна миграция `private/migrations/009-client-updates.sql`, для старых версий — полный `private/schema.sql`. Уведомления, шаблоны, архив, аккаунты, длительный вход и Web Push описаны там.

Начните с **UPDATE-CABINET-V15.md**. Обновление включает статус сервиса в шапке, полное удаление подписок/ключей из списка клиентов, массовую замену адреса в VLESS-ключах и сроки подписок с покупкой на несколько месяцев.

**Поверх v14 импортируйте `private/migrations/008-service-status.sql` в действующую базу из private/config.php**, затем загрузите файлы обновления с заменой и обновите браузер через Ctrl+F5. Для v13 сначала нужна `007-service-notice.sql`, для v8–v12 также `006-keenetic.sql`. Для v7 и старше или новой установки используйте полный `private/schema.sql`. Данные сохраняются; повторный импорт не сбрасывает настройки.

Свои `private/config.php`, `assets/config.js` и QR-код оставьте на сервере: обновление их не содержит. Доступ извне к private должен оставаться закрытым. Службу Ubuntu, её токен и SMTP менять не требуется.

После установки:

1. **Админка → Статус:** выберите зелёный, жёлтый или красный цвет и свой текст. Яркая кнопка «Статус сервиса» находится слева от выхода; общий статус — между именем и кнопками.
2. **Админка → Клиенты:** полное удаление подписки и ключа доступно рядом с каждой записью. История оплаченных заявок сохраняется без удалённого URL.
3. **Админка → Ключи роутеров:** введите новый адрес, при необходимости старый адрес-фильтр, выполните предпросмотр и примените замену. UUID, порт, SNI и остальные параметры сохраняются. Уже настроенные роутеры обновляются новым ключом вручную.
4. **Админка → Сроки подписок:** настройте уже существующие ссылки как бессрочные или укажите дату/продление. Без настройки они показывают «Срок не указан» и продолжают работать как прежде.

Новые помесячные покупки позволяют выбрать 1–12 месяцев по прежнему тарифу × количество месяцев, без дополнительной скидки. После подтверждения оплаты и выдачи ссылки срок назначается автоматически. Просроченная ссылка скрывается в кабинете и клиентских ответах сервера; отключение самого VPN в 3x-ui выполняется отдельно.

Требуются PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. Для загрузок: upload_max_filesize=5M, post_max_size=20M. Первичное подключение MySQL — в DATABASE-SETUP.md, мониторинг и почта — в MONITORING-SETUP.md.
