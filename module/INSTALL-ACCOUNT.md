# Кабинет МосКомпРемонт — текущая версия v11

Начните с UPDATE-CABINET-V11.md. Добавлены отдельные руководства обновления списка серверов V2RayN, переключения сервера и замены ссылки OpenWrt/Podkop. В кабинете из инструкций можно перейти как к подпискам, так и к ключам для роутера.

После установленной v8–v10 достаточно загрузить файлы обновления с заменой и обновить страницу через Ctrl+F5. Импорт SQL и переустановка службы Ubuntu не требуются. Для v5–v7 импортируйте private/migrations/005-monitoring.sql в текущую базу из private/config.php. Для v4 и старше или новой установки используйте полный private/schema.sql: он создаёт недостающие таблицы и сохраняет записи.

Каталог содержит 11 руководств и все 17 изображений предыдущей сборки. Новые скриншоты из чата ожидают оригинальных файлов, как описано в UPDATE-CABINET-V11.md. Установка Ubuntu-службы и настройка Яндекс Почты — в MONITORING-SETUP.md.

Сохранены мониторинг подписки, список клиентов с привязанными подписками и ключами, удаление ключей, фоновая обработка почты и её диагностика, пароль от 6 символов, поле «Telegram / номер телефона», ручная выдача подписок и ключей, импорт CSV, оплата и поддержка с фотографиями.

Требуются PHP 8.1+ с pdo_mysql/fileinfo/openssl/сессиями, MySQL 8+ или MariaDB 10.6+, HTTPS. PHPMailer включён с лицензией. Для Ubuntu-службы — SSH с sudo/root, Python 3.8+, curl и Xray из 3x-ui.

Свои private/config.php, assets/config.js и QR-код оставьте на сервере: архив обновления их не содержит. Настоящих паролей, подписки для мониторинга и клиентской базы в исходниках нет.
