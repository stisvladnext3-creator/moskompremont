# v4: назначение подписок клиенту без оплаты

Теперь администратор может выдать клиенту одну или несколько ссылок сразу — без заявки, банковской оплаты и подтверждения платежа. Назначение доступно только администратору.

## Установка

Если уже установлена v3:

1. Сохраните резервную копию файлов сайта.
2. Загрузите файлы обновления в папку сайта, сохранив структуру. Основные изменения: account.html, assets/account.js, assets/account.css, api/account.php и private/runtime.php.
3. Обновите account.html через Ctrl+F5.

**Базу для перехода с v3 на v4 импортировать не нужно: структура таблиц не менялась.** Существующий config.php, пароли БД/почты, QR и все аккаунты сохраняются. В архиве обновления этих рабочих конфигурационных файлов нет.

Если у вас ещё v1/v2 или новая установка, сначала импортируйте private/schema.sql в базу, указанную в dsn вашего config.php. Полный скрипт только создаёт отсутствующие таблицы и не удаляет записи. Архив v4 включает возможности v3: снятие привязки, приватные фото в поддержке и защиту ответов API.

## Назначить готовые подписки из базы

1. Войдите в админку → «База подписок».
2. В верхнем блоке «Назначить подписки клиенту» найдите клиента по имени, почте, Telegram или ID.
3. Выберите его в поле «Клиент», проверьте имя и почту.
4. В поле «Названия подписок из базы» напишите одно или несколько названий через пробел, запятую, точку с запятой или с новой строки. Например: `VPN5089, VPN5090 VPN5091`.
5. Нажмите «Назначить клиенту».

Ссылки будут доступны клиенту в «Моих подписках» после обновления списка/страницы. Если подписка уже принадлежит ему, дубликат не создаётся.

В карточке свободной подписки в базе также есть кнопка «Назначить клиенту»: она добавляет название в форму назначения. Остаётся выбрать получателя и отправить форму.

## Добавить новые ссылки и сразу выдать

1. В том же блоке выберите клиента.
2. В «Новых подписках со ссылками» укажите название и URL.
3. Чтобы добавить несколько ссылок, нажмите «Добавить ещё ссылку» и заполните дополнительные строки.
4. Нажмите «Назначить клиенту».

Новые записи сохранятся в базе и привяжутся к выбранному пользователю. Можно одновременно назначить готовые названия из базы и добавить новые ссылки — всего до 20 уникальных подписок за одну отправку.

Для названий действуют прежние правила: латинские буквы, цифры, точка, дефис, подчёркивание, до 100 символов. Если это название уже есть в базе с другой ссылкой, сайт попросит использовать существующую запись по названию или выбрать новое название. Адрес существующей подписки молча не заменяется.

## Быстро выбрать клиента

В «Новых пользователях» у каждого клиента есть кнопка «Назначить подписки». Она открывает форму с уже выбранным получателем. Для поиска старых клиентов можно использовать поиск в форме назначения: он проверяет всю базу пользователей, а не только открытую страницу списка.

## Привязки и оплаты

- Назначение без оплаты не создаёт фиктивную заявку или платёж и не меняет статус существующих заявок.
- Старая выдача через раздел «Оплаты» по-прежнему требует подтверждённого поступления.
- Ссылку, принадлежащую другому клиенту, нельзя перезаписать. Сначала используйте «Снять привязку», затем назначьте её новому владельцу.
- Ручное назначение может восстановить ранее снятую привязку этому же клиенту. Клиент сам восстановить её через поиск не может.
- Если хотя бы одна запись в пакете недоступна или содержит ошибку, весь пакет откатывается: частичной выдачи нет.
- Повторная отправка тех же названий и ссылок тому же клиенту не создаёт дубликатов.
- Действие фиксируется во внутреннем журнале администратора. Письма клиентам с подписочными ссылками не отправляются, ссылки доступны в кабинете.

Обновление управляет ссылками в кабинете. Оно не создаёт и не активирует VPN-подписки во внешней системе — вставляйте подготовленные вами рабочие ссылки.
