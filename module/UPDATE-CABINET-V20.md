# Обновление кабинета: продление подписок и версии приложений

В оплате появился выбор «Новая подписка» / «Продление имеющейся подписки». Клиент выбирает свою подписку, число месяцев и количество устройств. Сумма считается по действующему месячному тарифу без дополнительной скидки.

После «Я оплатил» заявка поступает администратору. Кнопка «Подтвердить оплату и продлить» одновременно подтверждает оплату и добавляет срок выбранной подписке. Повторно выдавать ссылку не нужно. Повторное подтверждение одной заявки не добавляет срок ещё раз.

- Действующая подписка продлевается от текущей даты окончания.
- Истёкшая подписка и подписка без указанного срока получают срок от даты подтверждения оплаты.
- Бессрочную подписку продлевать не требуется.
- Если подписка удалена или передана другому клиенту, подтверждение продления блокируется. Заявку можно отклонить и связаться с клиентом.
- Клиент получает уведомление в кабинете; при включённом Web Push — также push. В письме администратору об оплате указано название продлеваемой подписки.

На странице скачивания указаны Windows **0.3.17** и Android **0.1.17**. В обоих приложениях есть «☰ → Управление подписками» с подтверждением удаления вручную добавленных подписок. Подписки из кабинета управляются через сайт. Ссылки страницы не откатываются к старой версии при запоздавшем ответе GitHub API.

## Как установить на действующий сайт

1. Сохраните резервную копию файлов сайта и базы данных.
2. Распакуйте `moskompremont-cabinet-v20-update.zip` в папку сайта, где лежит `account.html`, с заменой одноимённых файлов. Объедините папки `assets`, `api` и `private` с существующими. Загрузите все файлы обновления вместе.
3. В панели хостинга откройте **действующую базу пользователей этого кабинета** и импортируйте `private/migrations/010-order-renewals.sql`. Повторный импорт безопасен. Предыдущие таблицы кабинета и миграции до 009 уже должны быть установлены; для новой установки используйте полный `private/schema.sql`.
4. Откройте `account.html`, обновите страницу без кеша. В клиентском кабинете выберите «Оплата и заявки → Продление имеющейся подписки». В админке подтвердите тестовую оплату только после фактической проверки перевода. Проверьте новую дату в «Моих подписках».
5. Проверьте `https://moskompremont.ru/download.html`: Windows 0.3.17, Android 0.1.17. Приложения устанавливайте поверх предыдущих версий.

Архив не содержит рабочего `private/config.php`, клиентских CSV, паролей и QR-кода банка. Ваши настройки базы, SMTP и реквизиты сохраняются. Настройка срока относится к учёту в личном кабинете; существующие подключения к внешним VPN-панелям этим обновлением не меняются.

Проверены PHP и MySQL/MariaDB, обновление базы без изменения старых заказов, будущий/истёкший/неуказанный срок, границы календарных месяцев, чужая и удалённая подписка, бессрочный срок, отказ в оплате, повторное и одновременное подтверждение, откат при ошибке и покупка новой подписки. Интерфейс проверен в браузере на ширинах 390 и 1280 px.

Основной PHP-хостинг обновляется загрузкой архива. Отдельный предпросмотр в ChatGPT показывает оформление страницы скачивания.
