# v17.1 — полный текст объявления в шапке кабинета

Убрано CSS-ограничение в три строки. Зелёный, жёлтый и красный блок статуса в профиле растёт по высоте, показывает весь текст объявления и сохраняет переносы строк. Длинные слова и ссылки переносятся внутри блока. Исправление работает для клиента и администратора, на компьютере и телефоне.

## Быстрая установка исправления

1. Скачайте `moskompremont-announcement-fix.zip` и распакуйте его на компьютере.
2. Загрузите с заменой в папку сайта, где находится кабинет, один файл:

```text
assets/account.css
```

3. Откройте кабинет и обновите страницу с очисткой кеша — **Ctrl+F5** на ПК. На телефоне обновите страницу; при необходимости закройте и заново откройте установленное приложение.

Блок увеличится автоматически. **Импорт SQL и изменение конфигурации не нужны.** Сохранённое объявление берётся из существующей базы.

В `assets/account.css` удалены свойства `display:-webkit-box`, `-webkit-line-clamp:3`, `-webkit-box-orient:vertical` и `overflow:hidden` из правила `.service-summary p`; теперь используется `display:block`. В полном архиве также обновлён `account.html`: версия подключения CSS теперь `v=17.1`. В небольшом исправлении достаточно заменить CSS и выполнить Ctrl+F5.

Полный накопительный архив — `moskompremont-cabinet-v17.1-update.zip`. Его используйте для перехода со старых версий; сохраняйте рабочие `private/config.php`, `assets/config.js` и QR. Для v16 и v17 SQL не требуется, для v15 нужна миграция `009-client-updates.sql`, для более старых версий — полный `private/schema.sql`. Функции v17 описаны в [UPDATE-CABINET-V17.md](UPDATE-CABINET-V17.md).
