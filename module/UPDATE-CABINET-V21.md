# Обновление v21: OpenWrt / Podkop

Добавлены вкладки **OpenWrt** клиенту и администратору. В кабинете создаётся отдельный код для одного роутера с выбором конкретной подписки или ключа клиента. Пароль от аккаунта в роутер не вводится. На странице видны время последней связи и результат применения; ненужный код можно отключить.

После установки пакета на роутер и привязки через LuCI по умолчанию включена автоматическая замена раз в 15 минут. Если конфигурация неизвестна или нельзя однозначно найти текущее подключение в подписке, пакет показывает новые данные для ручной замены. В кабинет приходят уведомления о результате обновления. При включённом Web Push используются существующие push-уведомления сайта.

## Как обновить действующий сайт

1. Сделайте резервную копию файлов сайта и базы пользователей.
2. Распакуйте **moskompremont-cabinet-v21-update.zip** в папку с `account.html`, замените одноимённые файлы, объедините папки. Рабочего `private/config.php`, QR оплаты и клиентских CSV в архиве нет.
3. В панели хостинга выберите **существующую базу кабинета**, импортируйте **private/migrations/011-router-devices.sql**. Это новая таблица кодов устройств; существующие аккаунты, подписки, заявки и сроки не удаляются. Повторный импорт безопасен. Для кабинета v20 достаточно этой миграции; более старые обновляйте миграциями по порядку. Для новой базы используйте полный `private/schema.sql`.
4. Проверьте `origin` в существующем `private/config.php`: `https://moskompremont.ru`. Если кабинет в подпапке, проверьте `app_path`. В коде для роутера кабинет сам покажет правильный адрес API. Этот обработчик должен быть доступен по HTTPS.
5. Обновите `account.html` без кеша. Клиент: **OpenWrt → название роутера → выбрать ключ/подписку → Создать код**. Администратор в своей вкладке OpenWrt сначала находит клиента и выбирает его запись.
6. Установите на роутер подходящие пакеты `mkr-router-updater` и `luci-app-mkr-router`. Откройте **Сервисы → МосКомпРемонт**, вставьте показанные адрес API и код. Оставьте автоматический режим. При нескольких секциях Podkop выберите нужную, сохраните и проверьте.

Код показывается один раз, действует год и разрешает только выбранную запись. В базе хранится хеш. При смене пароля, удалении аккаунта и снятии/передаче привязки доступ прекращается. Истечение срока подписки приостанавливает получение ссылки до продления. При сетевой ошибке уже установленное подключение на роутере сохраняется.

Ранее добавленные функции кабинета, продление подписок после подтверждения оплаты, Windows 0.3.17 и Android 0.1.17 сохранены. Рабочий PHP-хостинг обновляется загрузкой архива; публикация GitHub сама файлы вашего хостинга не заменяет.

Проверены PHP/MySQL, повторная миграция, разграничение доступа/CSRF, отключение кода, обновление URL, уведомления, истечение/продление срока и интерфейс кабинета на 390/1280 px. Пакеты проверяются штатными opkg/apk и UCI на официальных rootfs OpenWrt 24.10.4 и 25.12.5, с конфигурациями Podkop 0.3–0.6 и имитацией служб для проверки отката. Реального роутера пока нет; первый запуск выполняйте на одном тестовом устройстве с доступом LuCI/SSH.
