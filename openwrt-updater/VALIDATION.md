# Проверка OpenWrt 0.1.0 / кабинет v21

- Настоящие официальные rootfs **OpenWrt 24.10.4 и 25.12.5 x86_64**, закреплённые SHA-256 в `tests/platforms.json`.
- Штатные **opkg / apk v3**: установка core + LuCI, повторная установка, сохранение кода в конфигурации.
- Настоящие **rpcd / ubus**, обнаружение объекта `mkr-router` и получение состояния без секрета устройства.
- Настоящие **UCI, BusyBox, jq без regex**: схемы Podkop 0.3.4, 0.4.11, 0.5.8, 0.6.1, автоматическая замена и режим уведомления, неизменённая ссылка без перезапуска, сохранение других секций и DNS.
- HTTPS-подписки URI / base64, поиск текущего узла при замене домена/IP, неоднозначность, неизвестная версия/схема, многострочные запасные подключения, ручные и несохранённые изменения.
- Откат после ошибки перезапуска/проверки конфигурации, восстановление журнала прерванного обновления, сетевые ошибки и отключённый код, безопасное сохранение строк с кавычками и символами shell. Токен не передаётся в аргументах curl и на сервер подписки.
- PHP/MySQL: повторная миграция 011, создание клиентом/администратором, CSRF/роли/чужие ресурсы, хранение хеша, изменение URL при сохранении кода, уведомление без дублей, истечение и продление, отзыв, снятие привязки, смена владельца/пароля и удаление аккаунта.
- Chromium: личный кабинет на **390 и 1280 px**, создание клиентского/администраторского кода, доступ только к своим источникам, очистка одноразового кода при смене вкладки/выходе, отключение устройства; ошибок JavaScript нет.

В функциональных тестах службы **Podkop/sing-box и удалённые ответы имитируются**. Пакет не испытывался на физическом роутере и не проверял настоящий VPN-трафик. Установка на ARM/MIPS не проверялась аппаратно; сами пакеты содержат только shell/JavaScript/UCI и используют зависимости прошивки. Успешная проверка конфигурации и процесса не подтверждает доступность внешнего сервера. Перед массовой установкой нужна проверка на одном вашем роутере.

Код воспроизводимых проверок находится в `openwrt-updater/tests`. Сборка GitHub публикует релиз только после прохождения проверок установки, поведения, API и интерфейса.
