Обновление ссылки клиента на OpenWrt / Podkop с автоматической заменой по умолчанию.

- `moskom-openwrt-0.1.1.zip` — пакет для роутера: core + LuCI в IPK и APK, контрольные суммы и инструкция.
- `moskompremont-cabinet-v21-update.zip` — обновление существующего PHP-кабинета. После загрузки файлов импортируйте **private/migrations/011-router-devices.sql** в существующую базу пользователей.
- В кабинете появилась вкладка **OpenWrt** для выдачи/отключения кода устройства с выбором одной подписки или ключа.
- В роутере: **Сервисы → МосКомпРемонт**, вставить адрес API и код, сохранить и проверить.

IPK для opkg (OpenWrt 23.05/24.10), APK v3 для apk (25.12). Поддерживаются обычные секции `proxy / url` Podkop 0.3–0.6. Для сложных/неизвестных конфигураций и неоднозначных подписок включается ручная замена. Проверка по умолчанию каждые 15 минут.

Проверены установка штатными менеджерами, UCI, rpcd/ubus, откат и кабинет. Физического роутера пока нет: перед массовой установкой проверьте на одном устройстве. Подробности и границы проверки — `VALIDATION.md`.

Клиентских ссылок, паролей, QR оплаты и рабочего config.php в архивах нет. PHP-хостинг обновляется загрузкой архива; публикация GitHub сама его не заменяет.
