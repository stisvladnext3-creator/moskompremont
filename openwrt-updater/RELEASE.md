Исправлена автоматическая замена для Podkop 0.7.22 на OpenWrt с apk 3.

Добавлен `install.sh`: он одной командой определяет `apk`/`opkg`, скачивает нужные пакеты из релиза и проверяет SHA-256 до установки.

- Версия пакета определяется через `apk info -e -v`; при необходимости читается встроенная версия Podkop.
- Поддержаны `connection_type=proxy`, секции типа `section` и путь конфигурации sing-box в `settings`. Старые Podkop 0.3–0.6 сохраняются.
- Сохраняются код устройства и выбранная секция при обновлении с 0.1.1. Автоматическая замена по умолчанию, резервная копия и откат сохраняются.

**Как обновить:** скачайте два APK на компьютер, перенесите в `/tmp` роутера через WinSCP (SCP), затем выполните в SSH:

```sh
apk add --allow-untrusted /tmp/mkr-router-updater-0.1.2-r1.apk /tmp/luci-app-mkr-router-0.1.2-r1.apk
/etc/init.d/rpcd restart
```

Заново войдите в LuCI, обновите страницу без кеша, откройте «Сервисы → МосКомпРемонт» и нажмите «Сохранить и проверить». Флаг нужен для наших неподписанных APK; глобальную проверку подписей отключать не нужно. Для opkg в этом же релизе приложены два IPK. Полная инструкция, контрольные суммы и исходники входят в релиз.

Для этого исправления не требуются новая миграция или повторная загрузка сайта. К Podkop, прошивке и существующим настройкам VPN пакет обновления версии не применяет.

Проверено в официальных rootfs OpenWrt 24.10.4/25.12.5 с настоящими UCI, opkg/apk и rpcd. Формат настроек 0.7.22 взят из закреплённого исходника Podkop. Службы VPN и внешний сайт в сценариях имитируются; физический Cudy WR3000S v1 и реальный VPN-трафик не проверялись. Для selector/urltest/outbound и неоднозначных подписок остаётся ручной режим.
