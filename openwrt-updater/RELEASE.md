Обновление пакета OpenWrt/Podkop 0.1.5.

Исправлена маршрутизация Podkop «Всё, кроме РФ»: из основной секции больше не записывается текстовый список `0.0.0.0/0 ::/0`; российские адреса исключаются через официальный SagerNet `geoip-ru.srs`, а адрес роутера `192.168.31.1` добавляется в динамический список исключений. Добавлен режим «Podkop», который сохраняет маршрутизацию самого Podkop. Для Speedtest добавлено отдельное прокси-правило доменов Ookla. В LuCI добавлен выбор последней и предыдущей версии пакета.

Добавлен `install.sh`: он одной командой определяет `apk`/`opkg`, скачивает нужные пакеты из релиза и проверяет SHA-256 до установки.

- Версия пакета определяется через `apk info -e -v`; при необходимости читается встроенная версия Podkop.
- Поддержаны `connection_type=proxy`, секции типа `section` и путь конфигурации sing-box в `settings`. Старые Podkop 0.3–0.6 сохраняются.
- Сохраняются код устройства и выбранная секция при обновлении с 0.1.1. Автоматическая замена по умолчанию, резервная копия и откат сохраняются.

**Как обновить:** скачайте два APK на компьютер, перенесите в `/tmp` роутера через WinSCP (SCP), затем выполните в SSH:

```sh
apk add --allow-untrusted /tmp/mkr-router-updater-0.1.5-r1.apk /tmp/luci-app-mkr-router-0.1.5-r1.apk
/etc/init.d/rpcd restart
```

Заново войдите в LuCI, обновите страницу без кеша, откройте «Сервисы → МосКомпРемонт» и нажмите «Сохранить и проверить». Флаг нужен для наших неподписанных APK; глобальную проверку подписей отключать не нужно. Для opkg в этом же релизе приложены два IPK. Полная инструкция, контрольные суммы и исходники входят в релиз.

К Podkop, прошивке, сайту и существующим настройкам VPN пакет обновления версии не применяет.

Проверено в официальных rootfs OpenWrt 24.10.4/25.12.5 с настоящими UCI, opkg/apk и rpcd. Формат настроек 0.7.22 взят из закреплённого исходника Podkop. Службы VPN и внешний сайт в сценариях имитируются; физический роутер и реальный VPN-трафик не проверялись. Для selector/urltest/outbound и неоднозначных подписок остаётся ручной режим.
