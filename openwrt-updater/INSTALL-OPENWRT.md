# Установка обновления ссылок на роутеры

Сначала обновите сайт, затем установите два пакета на роутер. На каждый роутер создаётся свой код с выбором одной подписки или ключа.

## 1. Обновить сайт

1. Сохраните копию файлов сайта и базы пользователей.
2. Распакуйте `moskompremont-cabinet-v21-update.zip` в папку сайта с `account.html`, объединяя папки и заменяя одноимённые файлы. Рабочего `private/config.php`, QR банка и клиентских CSV в архиве нет — существующие настройки сохранятся.
3. В панели хостинга откройте **существующую базу кабинета**, вкладку SQL/импорт, выберите `private/migrations/011-router-devices.sql` из архива. Выполните импорт. Повторный импорт безопасен. Если кабинет ещё старее v20, сначала установите предыдущие миграции по порядку; новый сайт устанавливается полным `private/schema.sql`.
4. Проверьте в `private/config.php` значение `origin`: `https://moskompremont.ru` (без `/account.html`). Если кабинет находится в подпапке, `app_path` должен содержать её имя. PHP-обработчики должны быть доступны по HTTPS с действующим сертификатом.
5. Обновите страницу кабинета без кеша. У клиента и администратора появится вкладка **OpenWrt**. Учётные записи и старые привязки сохраняются.

## 2. Установить на OpenWrt

1. В **Статус → Обзор** посмотрите версию OpenWrt. Podkop уже должен быть установлен и настроен с работающим подключением.
2. Распакуйте `moskom-openwrt-0.1.1.zip` на компьютере. Для **23.05/24.10** нужны два файла `.ipk`; для **25.12** — два файла `.apk`. Это разные форматы, переименовывать их нельзя.
3. В **Система → Программное обеспечение** обновите списки пакетов. Через **Загрузить пакет** сначала установите `mkr-router-updater`, затем `luci-app-mkr-router` подходящего формата. Зависимости загружаются из репозиториев вашей прошивки; нужен доступ в интернет и свободное место.
4. Обновите страницу LuCI. Появится **Сервисы → МосКомпРемонт**. Если пункта нет, выйдите и снова войдите в LuCI.

Альтернатива через SSH — скопируйте оба файла в `/tmp` (например через SCP). Для opkg:

```sh
opkg update
opkg install /tmp/mkr-router-updater_0.1.1-1_all.ipk
opkg install /tmp/luci-app-mkr-router_0.1.1-1_all.ipk
```

Для apk:

```sh
apk update
apk add --allow-untrusted /tmp/mkr-router-updater-0.1.1-r1.apk
apk add --allow-untrusted /tmp/luci-app-mkr-router-0.1.1-r1.apk
```

APK устанавливаются локально, поэтому нужен `--allow-untrusted`. Перед установкой сверьте файлы с `SHA256SUMS.txt` из того же релиза. Пакет не заменяет Podkop и не требует смены прошивки.

## 3. Привязать к кабинету

1. На сайте клиент открывает **Личный кабинет → OpenWrt**.
2. Вводит название роутера, выбирает назначенный ему ключ или подписку, нажимает **Создать код устройства**. Администратор может сделать это в своей вкладке OpenWrt, сначала найдя нужного клиента.
3. Скопируйте показанные **Адрес API** и **Код устройства**. Вставьте их в **Сервисы → МосКомпРемонт** на роутере.
4. Оставьте **Автоматическая замена**, интервал **15 минут**. Если секций Podkop несколько, выберите нужную. Нажмите **Сохранить и проверить**.
5. После проверки появится «Установлена актуальная ссылка» или «Ссылка обновлена». В кабинете отобразятся время связи и результат. Если требуется ручная настройка, новая ссылка будет показана для копирования вместе с причиной.

Код не восстанавливается из кабинета. Если потеряли его, отключите старый и создайте новый. После смены пароля аккаунта роутер также нужно подключить заново. Один и тот же код не переносите на несколько роутеров.

## Проверка обновления

Администратор меняет домен/IP ключей или импортирует новые ссылки CSV. Не позже следующей плановой проверки роутер получает новую запись. Кнопка **Проверить сейчас** запускает проверку сразу. В режиме «Только уведомлять» появится новая ссылка и кнопка «Применить обновление»; клиент также получит уведомление в кабинете. Push придёт при включённом Web Push сайта.

Если интернет недоступен, код отключён или срок подписки истёк, текущая настройка Podkop сохраняется. Для нескольких серверов в подписке требуется однозначное совпадение с текущим подключением; произвольный сервер пакет не выбирает.

## Если нужна помощь

На роутере выполните:

```sh
cat /etc/openwrt_release
mkr-router status
logread -e mkr-router
```

Перед передачей вывода удалите ссылки/ключи из секции `pending`, если она присутствует. Код устройства и пароль присылать не нужно. Не отправляйте полный `uci show`: там могут быть секреты.

Пакеты проверяются на официальных rootfs OpenWrt 24.10.4 и 25.12.5. Реального роутера пока нет; первая установка нужна на одном тестовом устройстве с возможностью зайти в LuCI/SSH для проверки подключения. Проверка службы sing-box не заменяет проверку трафика через настоящий роутер.
