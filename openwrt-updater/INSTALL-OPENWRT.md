# Установка обновления ссылок на роутеры

Сначала обновите сайт, затем установите два пакета на роутер. На каждый роутер создаётся свой код с выбором одной подписки или ключа.

## Обновление пакета с 0.1.1 до 0.1.2

Исправлены Podkop 0.7.22: определение версии в apk 3, поля `connection_type` и настройки в секции `settings`. Для этого исправления достаточно обновить оба пакета на роутере поверх прежних, перезапустить rpcd и заново войти в LuCI. Сохранённые код устройства, адрес API и выбранная секция остаются. Нажмите **Сохранить и проверить**, чтобы повторить проверку. Повторно обновлять сайт или импортировать миграцию для этого исправления не нужно. При первой установке выполните следующие разделы.

## 1. Обновить сайт

1. Сохраните копию файлов сайта и базы пользователей.
2. Для первой установки поддержки OpenWrt скачайте [архив кабинета v21](https://github.com/stisvladnext3-creator/moskompremont/releases/download/moskom-openwrt-v0.1.1/moskompremont-cabinet-v21-update.zip) и распакуйте его в папку сайта с `account.html`, объединяя папки и заменяя одноимённые файлы. Рабочего `private/config.php`, QR банка и клиентских CSV в архиве нет — существующие настройки сохранятся.
3. В панели хостинга откройте **существующую базу кабинета**, вкладку SQL/импорт, выберите `private/migrations/011-router-devices.sql` из архива. Выполните импорт. Повторный импорт безопасен. Если кабинет ещё старее v20, сначала установите предыдущие миграции по порядку; новый сайт устанавливается полным `private/schema.sql`.
4. Проверьте в `private/config.php` значение `origin`: `https://moskompremont.ru` (без `/account.html`). Если кабинет находится в подпапке, `app_path` должен содержать её имя. PHP-обработчики должны быть доступны по HTTPS с действующим сертификатом.
5. Обновите страницу кабинета без кеша. У клиента и администратора появится вкладка **OpenWrt**. Учётные записи и старые привязки сохраняются.

## 2. Установить на OpenWrt

1. В **Статус → Обзор** посмотрите версию OpenWrt. Podkop уже должен быть установлен и настроен с работающим подключением.
2. Распакуйте `moskom-openwrt-0.1.2.zip` на компьютере. Для **23.05/24.10** нужны два файла `.ipk`; для **25.12** — два файла `.apk`. Это разные форматы, переименовывать их нельзя.
3. Для **opkg / IPK** в **Система → Программное обеспечение** обновите списки пакетов, затем через **Загрузить пакет** установите сначала `mkr-router-updater`, затем `luci-app-mkr-router`. Для **apk / APK** используйте SSH-команды ниже: штатная загрузка через LuCI не передаёт `--allow-untrusted`, поэтому отклоняет наши неподписанные пакеты с `UNTRUSTED signature`. Зависимости загружаются из репозиториев вашей прошивки; нужен доступ в интернет и свободное место.
4. Обновите страницу LuCI. Появится **Сервисы → МосКомпРемонт**. Если пункта нет, выйдите и снова войдите в LuCI.

### Установка одной командой

На роутере с доступом к GitHub можно скачать и установить подходящий формат одной командой. Скрипт сам выбирает `apk` для OpenWrt 25.12 или `opkg` для OpenWrt 23.05/24.10, скачивает `SHA256SUMS.txt`, проверяет каждый пакет и устанавливает только проверенные файлы:

```sh
wget -qO- https://raw.githubusercontent.com/stisvladnext3-creator/moskompremont/main/openwrt-updater/install.sh | sh
```

Для другого опубликованного выпуска можно указать его версию. Имена файлов должны соответствовать шаблону релиза 0.1.2:

```sh
wget -qO- https://raw.githubusercontent.com/stisvladnext3-creator/moskompremont/main/openwrt-updater/install.sh | MKR_RELEASE_VERSION=0.1.2 sh
```

Установка APK использует `--allow-untrusted` только для двух локально загруженных файлов после проверки SHA-256. Это не отключает проверку подписей в системе глобально. Если GitHub недоступен с роутера, используйте перенос файлов через WinSCP и блок проверки из раздела ниже.

Альтернатива через SSH — скопируйте оба файла в `/tmp` (например через SCP). Для opkg:

```sh
opkg update
opkg install /tmp/mkr-router-updater_0.1.2-1_all.ipk
opkg install /tmp/luci-app-mkr-router_0.1.2-1_all.ipk
```

Для apk:

```sh
apk update
apk add --allow-untrusted /tmp/mkr-router-updater-0.1.2-r1.apk
apk add --allow-untrusted /tmp/luci-app-mkr-router-0.1.2-r1.apk
```

Наши APK не подписаны доверенным ключом прошивки, поэтому для их установки нужен `--allow-untrusted`. Само по себе локальное расположение файла не требует этого флага. Перед установкой сверьте файлы с `SHA256SUMS.txt` из того же релиза. Флаг применяется к указанной команде; глобальную проверку подписей отключать не нужно. Пакет не заменяет Podkop и не требует смены прошивки.

Подписать APK ключом, которому уже доверяет произвольная прошивка OpenWrt, нельзя: такой закрытый ключ принадлежит сборке прошивки. Мы можем выпускать собственную подпись APK после создания отдельной пары ключей, хранения закрытого ключа только в GitHub Actions Secrets и установки нашего открытого ключа в `/etc/apk/keys/` на своих роутерах. До этого SHA-256 подтверждает целостность загрузки, но не заменяет подпись. Закрытый ключ в репозиторий и в архив релиза добавлять нельзя.

### Ошибка `UNTRUSTED signature` в LuCI

LuCI выполняет `apk add /tmp/upload.apk` без разрешения неподписанных пакетов. После попытки установки временный файл удаляется, поэтому установите оба пакета заново через SSH. Подключитесь к роутеру под root по его локальному адресу, затем выполните блок целиком:

```sh
(
  set -e
  release_url='https://github.com/stisvladnext3-creator/moskompremont/releases/download/moskom-openwrt-v0.1.2'
  wget -O /tmp/mkr-router-updater-0.1.2-r1.apk "$release_url/mkr-router-updater-0.1.2-r1.apk"
  wget -O /tmp/luci-app-mkr-router-0.1.2-r1.apk "$release_url/luci-app-mkr-router-0.1.2-r1.apk"
  sha256sum -c - <<'SHA256'
29413d04446484ce6c688c0375558beeb00b288f2c089b091fdc0329cf0ff7fd  /tmp/mkr-router-updater-0.1.2-r1.apk
ab7c8c548a2be8675c6a69b1980c644a7f7f02dc5026c6cb1f8a65d951b2b1f8  /tmp/luci-app-mkr-router-0.1.2-r1.apk
SHA256
  apk update
  apk add --allow-untrusted /tmp/mkr-router-updater-0.1.2-r1.apk /tmp/luci-app-mkr-router-0.1.2-r1.apk
)
```

Блок прекращает работу при ошибке скачивания или несовпадении контрольной суммы. После установки заново войдите в LuCI и откройте **Сервисы → МосКомпРемонт**.

### GitHub не скачивается: `Connection timed out`

Если `wget` пишет `Connecting to …:443` и `Connection timed out`, роутер не может установить соединение с GitHub. Повторная загрузка тем же способом не устраняет причину. Скачайте пакеты на компьютере и перенесите их в роутер по локальной сети:

1. Нажмите **Ctrl+C** в SSH-терминале, чтобы остановить зависшее скачивание или незавершённый ввод блока.
2. В браузере компьютера скачайте [mkr-router-updater-0.1.2-r1.apk](https://github.com/stisvladnext3-creator/moskompremont/releases/download/moskom-openwrt-v0.1.2/mkr-router-updater-0.1.2-r1.apk) и [luci-app-mkr-router-0.1.2-r1.apk](https://github.com/stisvladnext3-creator/moskompremont/releases/download/moskom-openwrt-v0.1.2/luci-app-mkr-router-0.1.2-r1.apk).
3. На Windows откройте WinSCP: протокол **SCP**, адрес роутера тот же, что используется для SSH/LuCI, порт **22**, пользователь **root**, пароль роутера. Выбирайте SCP: SFTP-сервер может отсутствовать в прошивке.
4. Перенесите оба файла в `/tmp` с исходными именами и заменой ранее скачанных файлов. Неудачный `wget -O` мог оставить пустой или неполный файл.
5. В SSH-терминале **роутера** выполните блок ниже. Он проверяет контрольные суммы, затем устанавливает локальные пакеты. Скачивать их с GitHub самому роутеру не требуется; зависимости при необходимости загружаются из репозиториев OpenWrt.

```sh
(
  set -e
  sha256sum -c - <<'SHA256'
29413d04446484ce6c688c0375558beeb00b288f2c089b091fdc0329cf0ff7fd  /tmp/mkr-router-updater-0.1.2-r1.apk
ab7c8c548a2be8675c6a69b1980c644a7f7f02dc5026c6cb1f8a65d951b2b1f8  /tmp/luci-app-mkr-router-0.1.2-r1.apk
SHA256
  apk add --allow-untrusted /tmp/mkr-router-updater-0.1.2-r1.apk /tmp/luci-app-mkr-router-0.1.2-r1.apk
)
```

После успешной установки заново войдите в LuCI и откройте **Сервисы → МосКомпРемонт**.

### Страница открывается, но `mkr-router/status`: `Object not found`

Страница LuCI обращается к объекту `mkr-router` службы rpcd. Такая ошибка означает, что объект отсутствует в ubus; это ещё не ошибка кода устройства или связи с сайтом. Сначала проверьте наличие файлов и заново загрузите обработчик. Выполните в SSH-терминале роутера под root:

```sh
ls -l /usr/bin/mkr-router /usr/libexec/rpcd/mkr-router
chmod 755 /usr/bin/mkr-router /usr/libexec/rpcd/mkr-router
/etc/init.d/rpcd restart
sleep 2
ubus -v list mkr-router
```

В последнем выводе должен появиться объект `mkr-router` с методами `status`, `check`, `apply`, `disable`, `configure`. После перезапуска rpcd заново войдите в LuCI и обновите страницу без кеша (Ctrl+F5 на Windows).

Если первый шаг сообщает `No such file or directory`, основной пакет установлен не полностью: повторно установите локальный файл `mkr-router-updater` подходящего формата, затем перезапустите rpcd. Если файлы на месте, но объекта всё ещё нет, для диагностики нужны вывод `ls -l` выше, `ubus -v list mkr-router` и `/usr/libexec/rpcd/mkr-router list`. Последняя команда выводит только описание методов, без кода устройства и подписочных ссылок. Полный статус с содержимым `pending`, настройки UCI и код устройства присылать не нужно.

## 3. Привязать к кабинету

1. На сайте клиент открывает **Личный кабинет → OpenWrt**.
2. Вводит название роутера, выбирает назначенный ему ключ или подписку, нажимает **Создать код устройства**. Администратор может сделать это в своей вкладке OpenWrt, сначала найдя нужного клиента.
3. Скопируйте показанные **Адрес API** и **Код устройства**. Вставьте их в **Сервисы → МосКомпРемонт** на роутере.
4. Оставьте **Автоматическая замена**, интервал **15 минут**. Если секций Podkop несколько, выберите нужную. Нажмите **Сохранить и проверить**.
5. После проверки появится «Установлена актуальная ссылка» или «Ссылка обновлена». В кабинете отобразятся время связи и результат. Если требуется ручная настройка, новая ссылка будет показана для копирования вместе с причиной.

Код не восстанавливается из кабинета. Если потеряли его, отключите старый и создайте новый. После смены пароля аккаунта роутер также нужно подключить заново. Один и тот же код не переносите на несколько роутеров.

## Проверка обновления

Администратор меняет домен/IP ключей или импортирует новые ссылки CSV. Не позже следующей плановой проверки роутер получает новую запись. Кнопка **Проверить сейчас** запускает проверку сразу. В режиме «Только уведомлять» появится новая ссылка и кнопка «Применить обновление»; клиент также получит уведомление в кабинете. Push придёт при включённом Web Push сайта.

Если интернет недоступен, код отключён или срок подписки истёк, текущая настройка Podkop сохраняется. Для нескольких серверов в подписке требуется однозначное совпадение с текущим подключением; произвольный сервер пакет не выбирает.

## Если нужна помощь

На роутере выполните:

```sh
cat /etc/openwrt_release
mkr-router status
logread -e mkr-router
```

Перед передачей вывода удалите ссылки/ключи из секции `pending`, если она присутствует. Код устройства и пароль присылать не нужно. Не отправляйте полный `uci show`: там могут быть секреты.

Пакеты проверяются на официальных rootfs OpenWrt 24.10.4 и 25.12.5. Реального роутера пока нет; первая установка нужна на одном тестовом устройстве с возможностью зайти в LuCI/SSH для проверки подключения. Проверка службы sing-box не заменяет проверку трафика через настоящий роутер.
# Выпуск 0.1.4

Выпуск 0.1.4 исправляет режим «Всё, кроме РФ»: Podkop получает geoip-ru.srs как remote rule-set sing-box и прямые доменные суффиксы `ru`/`xn--p1ai`, поэтому российские сайты не зависят от фоновой загрузки plain-text списка. Для новой установки или обновления используйте установщик — он сам выберет IPK/APK, скачает соответствующий релиз и проверит контрольные суммы:

```sh
wget -qO- https://raw.githubusercontent.com/stisvladnext3-creator/moskompremont/main/openwrt-updater/install.sh | sh
```

После установки откройте **Сервисы → МосКомпРемонт**, выберите секцию Podkop и режим маршрутизации, затем сохраните настройки. Подробное описание поведения и ограничений находится в `openwrt-updater/README.md`.
