- [Подключение MySQL — пошаговая инструкция](downloads/DATABASE-SETUP.md)

Требуется PHP 8.1+ с PDO MySQL и MySQL 8+ / MariaDB 10.6+. Архив содержит раздел «Мировой интернет» и кабинет для существующего сайта «МосКомпРемонт», а не исходники остальных разделов. В предпросмотре показан интерфейс; регистрация и платежи отключены. Рабочая регистрация и вход находятся в PHP-модуле архива и требуют установки на вашем сервере.

Оплата — по QR Озон Банка с ручной проверкой администратором. До добавления настоящего QR и имени получателя создание заявок отключено. Восстановление пароля и подтверждение почты письмом пока не подключены.

Архивы не содержат настроенных паролей базы, пользовательских записей и банковского QR. Существующий assets/config.js с вашими ссылками сохраняйте: в полном архиве поставляется только config.example.js.
