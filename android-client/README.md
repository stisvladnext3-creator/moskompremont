# МосКомпРемонт VPN для Android

Нативное Android-приложение с оболочкой сервиса на базе v2rayNG 2.3.15. Прямое распространение APK, Android 7/API 24 и новее. Идентификатор приложения: `ru.moskompremont.vpn`.

В приложении доступны кабинет moskompremont.ru, отдельный выбор подписки и сервера, импорт из буфера, обновление подписок, реальная проверка выбранного подключения, статус сервиса, три политики Russia, режимы «Выбранные приложения» и «Выбранные сервисы», DNS, обновление правил, обновление приложения и встроенная справка. Android использует системный `VpnService` и уведомление о подключении; права root не нужны. В меню ☰ выберите установленные приложения либо сервисы из списка 27 пунктов (включая FaceTime и Google Meet), затем включите соответствующий режим.

Ссылки кабинета получают стабильные группы по ID пользователя и подписки. Полный корректный ответ API удаляет истёкшие и отозванные группы, а ошибка сети сохраняет последние рабочие настройки. Выход удаляет только группы кабинета. Пароль не сохраняется; cookie сессии шифруются AES-GCM ключом Android Keystore. В рабочей сборке адрес кабинета фиксирован. Локальный тестовый адрес принимается только в DEBUG.

Сборка описана в [workflow](../.github/workflows/android-vpn.yml). Закреплённые версии v2rayNG, нативной AAR, HEV и Russia находятся в [sources.json](build/sources.json). Сгенерированные AAR, библиотеки и ключи подписи в репозиторий не входят. `prepare.py` применяют один раз к чистой закреплённой базе, `inputs.py` восстанавливает проверенные бинарные входные файлы. Выпускается универсальный APK с arm64-v8a, armeabi-v7a, x86_64 и x86.

Для обновления поверх опубликованной версии нужен тот же ключ подписи. Он хранится отдельно от публичных исходников. Не создавайте новый ключ для очередного выпуска.

`assembleFdroidRelease` создаёт неподписанный кандидат только для проверки в артефактах CI. Он не должен загружаться в публичный релиз: Android отклоняет такой APK как недействительный пакет. Публикация выполняется отдельно через `android-release.yml`: обязательны проверка постоянного сертификата, контрольных сумм и установка самого подписанного APK на Android 7 и 15, включая обновление поверх версии 0.1.29 с сохранением данных. Отсутствие подписи или другой сертификат останавливают публикацию.

Проверки включают JVM-тесты правил, DNS, версий и выбора групп, компиляцию, сборку APK и проверку на Android-эмуляторе. Локальный HTTP/VLESS стенд использует только вымышленные данные и не обращается к клиентским подпискам. Итоги конкретного выпуска приводятся в `VALIDATION.md` и отчётах CI.

Лицензия оболочки и базы — GPL-3.0; лицензии зависимостей остаются в соответствующих исходниках. Каждый выпуск сопровождается архивом исходного кода и SHA256SUMS.txt.

В меню ☰ есть «Управление подписками»: список добавленных вручную подписок, подтверждение удаления и удаление всех их серверов. Активная удаляемая подписка отключает VPN; удаление другой подписки сохраняет подключение. Подписки кабинета защищены в обработчике, отдельные ключи сохраняются. Изменение записей MMKV выполняется под существующей блокировкой индексов с восстановлением снимка при ошибке записи.

В меню «Сервисы» добавлены свои домены: сохраняются в MMKV вместе с выбором, поддерживают IDN и full:, включают VPN DNS и могут использоваться без галочек каталога. Политика медиа Telegram/WhatsApp общая с ПК; известные IP Meta являются общими для нескольких её сервисов.
