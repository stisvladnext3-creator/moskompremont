# МосКомпРемонт VPN для Android

Нативное Android-приложение с оболочкой сервиса на базе v2rayNG 2.3.15. Прямое распространение APK, Android 7/API 24 и новее. Идентификатор приложения: `ru.moskompremont.vpn`.

В приложении доступны кабинет moskompremont.ru, отдельный выбор подписки и сервера, импорт из буфера, обновление подписок, реальная проверка выбранного подключения, статус сервиса, три политики Russia, DNS, обновление правил, обновление приложения и встроенная справка. Android использует системный `VpnService` и уведомление о подключении; это платформенное отличие от системного прокси Windows.

Ссылки кабинета получают стабильные группы по ID пользователя и подписки. Полный корректный ответ API удаляет истёкшие и отозванные группы, а ошибка сети сохраняет последние рабочие настройки. Выход удаляет только группы кабинета. Пароль не сохраняется; cookie сессии шифруются AES-GCM ключом Android Keystore. В рабочей сборке адрес кабинета фиксирован. Локальный тестовый адрес принимается только в DEBUG.

Сборка описана в [workflow](../.github/workflows/android-vpn.yml). Закреплённые версии v2rayNG, нативной AAR, HEV и Russia находятся в [sources.json](build/sources.json). Сгенерированные AAR, библиотеки и ключи подписи в репозиторий не входят. `prepare.py` применяют один раз к чистой закреплённой базе, `inputs.py` восстанавливает проверенные бинарные входные файлы. Выпускается универсальный APK с arm64-v8a, armeabi-v7a, x86_64 и x86.

Для обновления поверх опубликованной версии нужен тот же ключ подписи. Он хранится отдельно от публичных исходников. Не создавайте новый ключ для очередного выпуска.

Проверки включают JVM-тесты правил, DNS, версий и выбора групп, компиляцию, сборку APK и проверку на Android-эмуляторе. Локальный HTTP/VLESS стенд использует только вымышленные данные и не обращается к клиентским подпискам. Итоги конкретного выпуска приводятся в `VALIDATION.md` и отчётах CI.
